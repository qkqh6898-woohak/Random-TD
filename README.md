# 운빨 디펜스 (Random-TD)

랜덤 소환 + 3개 합성 타워 디펜스 모바일 게임. 개인용, 오프라인 플레이, 인터넷은 업데이트에만 사용.

## 데이터와 도구

| 파일 | 내용 |
|------|------|
| `src/data/towers.json` | 타워 65종 스탯 (물리·마법 공격력, 공속, 사거리, 공격 범위, 관통, 치명타, 감지, 특색) |
| `src/data/enemies.json` | 몹 10종·보스 5종·도전 보스 10종, 등장 구성 |
| `src/data/maps/*.json` | 사거리 미로(96칸), 순환의 정원(71칸) |
| `tools/gen_tables.py` | 데이터 규칙 검사 + 문서 표 자동 생성 (`python3 tools/gen_tables.py`) |
