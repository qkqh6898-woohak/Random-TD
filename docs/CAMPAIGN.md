## 1. 구조 요약

| 항목 | 내용 |
|------|------|
| 테마 (= 챕터·맵) | **10개**, 테마마다 전용 맵·배경·특수 규칙·최종 보스 |
| 테마당 단계 | **50단계** (0단계 준비 + 1~50), 50단계 보스 처치 = 테마 클리어 |
| 발판 (체크포인트) | **10·20·30·40단계**. 한 번 넘은 발판부터 다시 시작 가능 |
| 발판 보상 | 각 발판을 **처음 넘을 때** 계정 보상 (4장) |
| 테마 해금 | 앞 테마 50단계 클리어 |
| 단계 표기 | `테마-단계` (예: 2-32 = 테마 2의 32단계) |
| 패배 조건 | 테마마다 목숨 20 (상점으로 최대 30) + 보스 60초 |
| 무한 모드 해금 | 캠페인 1-20 처음 클리어 |

### 1.1 예시: 2-32에서 실패하면

```
월드맵 · 테마 2 「두르가 광산 협곡」

  [0]──[10]──[20]──[30]──[40]──[50🏁]
   ✔     ✔     ✔    🧍           ← 지휘관 캐릭터가 2-30 발판 위에 서 있음
                     ↑
             2-32에서 패배 → 가장 멀리 넘은 발판 = 30

[2-30에서 시작] 버튼 → 31단계부터 시작 (지원금 37,000원 + 일꾼 10명 + 준비 120초)
[2-0부터 시작]  버튼 → 처음부터 (판 안 미션을 전부 다시 노릴 수 있음)
```

## 6. 배경 변화

### 6.1 테마 안에서 단계에 따라

| 단계 | 하늘·분위기 | 연출 |
|------|-----------|------|
| 1~10 | 맑은 낮 | 밝은 색, 새 날아감 |
| 11~20 | 노을 | 주황빛, 그림자 길어짐 |
| 21~30 | 밤 (달 2개·별) | 어두운 파랑, 타워 받침대 빛남 |
| 31~40 | 전운 (먹구름·비) | 비 파티클, 가끔 번개 |
| 41~50 | 침공 절정 | 하늘이 보라색으로 갈라짐, 운석·균열 번개 |
| 보스 단계 | 화면이 어두워지고 보스 색 오라 | 50단계는 테마 전용 결전 배경 |

- 배경은 3겹(먼 하늘 / 중간 풍경 / 맵 바닥)으로 나눠서 하늘만 바꾸고, 바뀔 때 2초 동안 서서히 전환
- 무한 모드: 50단계마다 테마 배경이 1→10 순서로 바뀌며 반복

### 6.2 테마별 기본 풍경

| 테마 | 풍경 |
|------|------|
| 1 국경 평원 | 초원, 성벽, 풍차 |
