# V2 PR-G — 전투 UI

검토 브랜치 design/v2-pr-g. PR 대상 design/v2-battle-base는 PR-F와 필드 #79를 합친 검토 전용 기준이다. 공통 main3abfda6, 선행 PR-B#73 → C#74 → D#77 → E#78 → F. main에는 병합·푸시하지 않고 서명 릴리스도 실행하지 않는다.

## 화면과 표시 계약

- 연속된 잔디·흙길과 오리지널 초록/노랑 숲 테두리. MapRenderer가 고정된 표시용 시드로 한 번 굽는 별도 텍스처다. 칸 바닥은 투명하며 선택/이동/강화 중에만 #79의 관련 칸 표시가 나타난다. 기존 배경 밴드·입구/출구·경로·충돌·배치 좌표를 유지한다.
- 갈색 웨이브/타이머·몬스터 수 바·보스 체력 자리, 노랑 소환+비용 알약·남색 강화·양옆 기존 리미티드/도박·고용·배속. 실제 메뉴/등급 이름과 자원을 사용한다. 준비 완료/모두 승급/도전/미션/개발자 선택자는 유지한다.
- 메뉴 → 기존 설정·일시정지/미션, 실제 HUD 값을 읽는 전투 통계(웨이브·시간·몹/목숨·골드·배치·일꾼·배속·천장). native dialog·뒤로 가기·초점 복귀·Escape/바깥 클릭을 지원한다. Android 뒤로 가기는 열린 전투 메뉴를 먼저 닫고 게임을 일시정지하지 않는다.
- 종이형 타워 정보·도전/강화/미션/리미티드 시트·보상 3장, 나무 제목·남색 X·초록 진행바·읽을 수 있는 등급 라벨. 드래그 시트 크기·기존 정보 밀도·판매 확인·비용/수령 판정은 그대로다.
- 실제 stageStart에 1.5초 WAVE 띠, 기존 보스 처치 알림은 노랑 리본, 최근 알림 두 줄은 전장 아래에 표시한다. 기존 aria-live 알림 외의 장식 띠/로그는 중복 낭독하지 않는다.
- 치명타는 하늘색 #4FD8F0 + 기존 큰 숫자/180ms 타격 효과. 기존 크기/겹침 방지/우선순위/연출 끄기와 고배속 예산을 유지한다.
- 선택창은 실제 **웨이브 남은 시간**을 표시한다. 꾹 눌러 전장을 볼 때 표시만 숨기고 놓기/취소/초점 상실 시 복원한다. 카드 선택/만료/자동 선택 규칙은 바꾸지 않는다.

## 작은 화면과 회귀 수정

320/360/393/412px, 터치44px, UI 글자12px 이상, 동작 줄이기, env 안전영역. 짧은 화면은 HUD 자원/몹 바를 한 줄로 묶고 버튼을 압축하며 보조 천장 수치는 통계에서도 확인한다. 가로 화면의 좁은 무대에서는 부가 힌트를 시각적으로 접되 접근성 텍스트를 유지한다. 선택창은 HUD 아래부터 하단 조작 위까지 스크롤하므로 일시정지를 가리지 않는다.

예전 HUD 배너 높이 실패4건을 UI에서 해결했다. 일반/두 줄 알림과 숨은 측정 요소에 같은 고정 높이를 주고, 웨이브/보스 제목 높이를 고정했다. ResizeObserver는 border-box를 관찰해 안전영역 패딩/테두리가 바뀌어도 맵을 다시 잰다. 기존 HUD 검사와 순수 배치 계산의 기대값을 낮추지 않았다.

기존 fb63의 비동기 debug 명령 뒤 즉시 merges를 읽던 검사는 같은 `>=3` 조건을 poll로 기다린다. 명령 처리 전에 가득 찬 무더기 목록이 비어 있는 잠깐을 통과하던 경쟁만 제거하며 실제 승급 수/비용 검증을 유지한다.
