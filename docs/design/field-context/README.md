# 조작 중에만 표시하는 전투 칸

`design/field-context`는 main `3abfda6` 기준의 독립 디자인 변경이다. PR-B~E와 별도로 검토할 수 있다. main 병합·푸시·서명 릴리스는 실행하지 않는다.

## 표시 계약

| 상태 | 칸 표시 |
| --- | --- |
| 시작 직후·전투 중·빈 곳/길 짧게 누르기·연속 소환 | 없음. 기존 배경 또는 절차 잔디가 이어짐 |
| 타워 선택, 판매 확인·승급 준비 | 선택한 종류의 내 타워가 있는 칸 |
| 길게 눌러 끌기·패널의 이동 모드 | 배치 가능한 전체 칸 + 기존 유효/불가 미리 보기 |
| 강화 창의 등급/능력치 탭 | 내 타워가 있는 칸 |
| 강화 창에서 도박 탭 | 없음 |
| 닫기·취소·선택 타워 판매로 사라짐·일시정지·게임 종료 | 없음 |

첫 소환 추천 칸과 첫 승급 결과/재료 안내는 기존 신규 플레이어 안내로 유지한다.

상시 체커색·십자 문양·칸별 가장자리를 정적 맵 텍스처에서 제거했다. 길·입구·출구·배경은 유지한다. 배경 그림이 없으면 기존 절차 잔디를 사용한다. 평소 오라 타워는 작은 발밑 빛으로 알리고 정확한 범위는 선택 중 표시한다. 같은 칸에 여러 타워가 있어도 칸은 한 번만 칠한다.

`Game.fieldHighlights`는 기존 선택/이동/강화 상태를 읽는 표시 전용 계산이다. `SelectionLayer`가 매 프레임 지우고 필요한 칸만 다시 그린다. 상태가 끝나면 타이머를 기다리지 않고 사라진다. `buildHint`는 실제 표시 칸이 있으면 1, 없으면 0인 읽기 전용 진단 값이다.

## 검토 경계

- `src/view/render/MapRenderer.ts`: 정적 소환 바닥 삭제, 새 텍스처 키.
- `src/view/render/SelectionLayer.ts`: 조작 칸 표시, 평소 오라를 발밑으로 축소.
- `src/view/scenes/Game.ts`: 표시할 칸 계산/전달. 예전 시작·길 탭 타이머 제거.
- `e2e/t3-screen.spec.ts`: 새 요청에 따라 시작/길 탭의 **숨김**을 명시적으로 검증. 소환·연속 소환·이동·취소의 기존 검증과 선택자는 보존.
- `e2e/field-context.spec.ts`: 정적 텍스처의 실제 알파 0, 네 모바일 폭의 선택·이동·취소·강화·판매, 캠페인 배경 누락/실제 드래그·드롭 검증.

sim/meta/save/data/경제/타워 ID/명령/충돌·배치 판정/지형 좌표/저장 형식은 수정하지 않는다. 기존 단축키와 DOM 선택자도 유지한다. `Game.ts`는 Claude와 공유하므로 표시 코드 주변만 검토한다. PR-G 전체 전투 UI 개편은 포함하지 않는다.

## 검증

최종 실행 결과와 캡처는 이 폴더의 validation.json 및 screens에 기록한다. 실제 Android 장치 검증은 별도다.


## 최종 검증 기록

전체 Canvas 회귀는 E+필드를 임시 로컬 통합한 d7ccb86에서 273개를 세 묶음으로 순차 실행해 262통과·5실패·6건너뜀이다. 수집/실행 ID 누락·중복0, 검사 전후 소스 해시 동일. 실제 배포 브랜치들은 분리하며 통합 작업본은 푸시하지 않는다.

실패는 기존 main에서 재현한 HUD 배너 예약 높이 4건과 환경의 file:// 관리자 차단 1건이다. 기존 HUD/file 검사 기대값은 바꾸지 않았다. HTTP 단일 HTML 확인을 file:// 통과로 세지 않는다.

독립 필드 작업본: unit111파일1,609통과·5건너뜀, check/build 통과. 관련 Canvas16/16, 최종 Canvas5/5, 기본 Chromium320px1/1. 모든 배치 칸 중앙의 정적 텍스처 알파0과 실제 선택/판매·승급/이동·취소/강화·일시정지/계속, 배경 누락 캠페인 드래그를 확인했다. 일반 잔디 캡처는 소환 연출 종료 뒤 다시 저장했다.

통합 배포/단일 HTML HTTP: 영웅 안내·상세·×16 새 게임·첫 소환 후978원·이어 하기, 로컬 폰트/아이콘/배경 디코딩 확인. 단일 파일은 문서1회·추가 자산 요청0·오류0. 실제 Android 장치는 검사하지 않았다.
