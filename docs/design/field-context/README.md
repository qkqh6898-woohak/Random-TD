# 조작 중에만 표시하는 전투 칸

`design/field-context`는 main `3abfda6` 기준의 독립 디자인 변경이다. PR-B~E와 별도로 검토할 수 있다. main 병합·푸시·서명 릴리스는 실행하지 않는다.

## 표시 계약

| 상태 | 칸 표시 |
| --- | --- |
| 시작 직후·전투 중·연속 소환(꾹 누르기) | 없음. 기존 배경 또는 절차 잔디가 이어짐 |
| 놓을 수 없는 곳(길·X 칸·맵 밖 땅) 짧게 누르기 | 1.2초 동안 배치 가능한 전체 칸 (끝 0.4초 서서히). 아래 '잘못 누르기 안내' |
| 타워 선택, 판매 확인·승급 준비 | 선택한 종류의 내 타워가 있는 칸 |
| 길게 눌러 끌기·패널의 이동 모드 | 배치 가능한 전체 칸 + 기존 유효/불가 미리 보기 |
| 강화 창의 등급/능력치 탭 | 내 타워가 있는 칸 |
| 강화 창에서 도박 탭 | 없음 |
| 닫기·취소·선택 타워 판매로 사라짐·일시정지·게임 종료 | 없음 |

첫 소환 추천 칸과 첫 승급 결과/재료 안내는 기존 신규 플레이어 안내로 유지한다.

상시 체커색·십자 문양·칸별 가장자리를 정적 맵 텍스처에서 제거했다. 길·입구·출구·배경은 유지한다. 배경 그림이 없으면 기존 절차 잔디를 사용한다. 평소 오라 타워는 작은 발밑 빛으로 알리고 정확한 범위는 선택 중 표시한다. 같은 칸에 여러 타워가 있어도 칸은 한 번만 칠한다.

`Game.fieldHighlights`는 기존 선택/이동/강화 상태를 읽는 표시 전용 계산이다. `SelectionLayer`가 매 프레임 지우고 필요한 칸만 다시 그린다. 조작 상태가 끝나면 타이머를 기다리지 않고 사라진다(잘못 누르기 안내만 시간으로 끝남). `buildHint`는 지금 칠하는 칸의 진하기(0~1)인 읽기 전용 진단 값이다: 선택·이동·강화 중 1, 잘못 누른 뒤 1 → 끝에 서서히 0, 평소 0.

## 검토 경계

- `src/view/render/MapRenderer.ts`: 정적 소환 바닥 삭제, 새 텍스처 키.
- `src/view/render/SelectionLayer.ts`: 조작 칸 표시, 평소 오라를 발밑으로 축소.
- `src/view/scenes/Game.ts`: 표시할 칸 계산/전달. 예전 시작 타이머 제거, 길 탭 타이머는 잘못 누르기 안내로 유지(#79 검토).
- `src/view/render/buildHint.ts`: 표시 칸 순수 계산 `fieldContext`·`buildHintAlpha`·`startsBuildHint` (단위 테스트 `tests/unit/t3-screen.test.ts`).
- `e2e/t3-screen.spec.ts`: 새 요청에 따라 시작의 **숨김**을 명시적으로 검증(길 탭은 #79 검토 수정으로 잠깐 표시). 소환·연속 소환·이동·취소의 기존 검증과 선택자는 보존.
- `e2e/field-context.spec.ts`: 정적 텍스처의 실제 알파 0, 네 모바일 폭의 선택·이동·취소·강화·판매, 캠페인 배경 누락/실제 드래그·드롭 검증.

sim/meta/save/data/경제/타워 ID/명령/충돌·배치 판정/지형 좌표/저장 형식은 수정하지 않는다. 기존 단축키와 DOM 선택자도 유지한다. `Game.ts`는 Claude와 공유하므로 표시 코드 주변만 검토한다. PR-G 전체 전투 UI 개편은 포함하지 않는다.

## 잘못 누르기 안내 (#79 검토 🔴 수정, Claude)

칸을 숨기면 캠페인 `crossroads`의 2×2 `B` 블록 사이 `X`(배치 불가) 칸과 `B`가 똑같이 보인다. 첫 타워를 놓아 추천 칸이 사라진 뒤 X 칸이나 길을 누르면 아무 반응이 없어 새 플레이어가 놓을 곳을 배울 수 없었다. 그래서 예전 T-3 `notBuildable` 탭 경로를 되살렸다.

- **언제**: 소환 검사가 `notBuildable`인 곳(길·X 칸·맵 밖 땅)을 **짧게** 눌렀을 때 (`startsBuildHint`). 맵 안은 손을 뗄 때, 맵 밖은 누를 때. 꾹 눌러 연속 소환이 시작됐으면 띄우지 않는다. 패널·시트가 열린 상태의 탭은 그것만 닫는다(기존 그대로).
- **무엇을**: `BUILD_HINT_MS` = 1200ms 동안 `map.buildable` 전체를 이동 모드와 같은 옅은 흰 네모로. 끝 `BUILD_HINT_FADE_MS` = 400ms 동안 서서히 사라진다. 연출 끄기면 서서히 사라지지 않고 1.2초 뒤 바로 꺼진다. 상수는 `src/view/render/buildHint.ts`(화면 전용, 데이터 JSON 아님).
- **시계**: 화면 시계(`scene.time.now`, 실제 시간). sim 틱과 무관해 배속과 상관없다.
- **우선순위**: 일시정지·게임 종료 → 없음 > 끌기·[↔ 이동] → 전체 칸 > 선택·강화 → 관련 칸 > 잘못 누르기 안내 > 없음.
- **지우기**: 일시정지·게임 종료·새 판(다시 하기 포함)·빈 칸 소환 탭이면 바로 지운다. 판 시작에는 띄우지 않는다(평소 숨김 유지).
- sim·명령·데이터·배치 판정·좌표는 그대로다. `SIM_VERSION` 변화 없음.
- 검증: `tests/unit/t3-screen.test.ts`(안내 시작 조건·시간·일시정지·우선순위), `e2e/field-context.spec.ts` 'mis-tap hint'(crossroads X 칸 (3,7)·(6,1)·길 (3,3), circle 길 (0,3) → 전체 칸 표시 → 약 1.2초 뒤 0, 일시정지가 지움, 배치 칸 탭은 그대로 소환), `e2e/t3-screen.spec.ts` 길 탭 기대값을 다시 '잠깐 보임'으로.
