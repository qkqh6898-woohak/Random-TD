> 관련: [GDD.md](GDD.md) (규칙), [TOWERS.md](TOWERS.md)·[ENEMIES.md](ENEMIES.md) (수치), [ARCHITECTURE.md](ARCHITECTURE.md) (구조), [MULTIPLAYER.md](MULTIPLAYER.md) (결정성 규칙)

## 0. 개발 원칙

| 원칙 | 구체적으로 |
|------|-----------|
| 규칙과 화면 분리 | `src/sim/`(게임 로직)은 Phaser·DOM을 모른다. `src/view/`는 sim 상태를 읽어서 그리기만 한다 |
| 결정성 | sim 안에서 `Math.random`·`Date`·`performance.now`·`Math.pow/exp/sin/cos` 금지. 검사 스크립트가 잡아냄 ([MULTIPLAYER.md](MULTIPLAYER.md) 4.2) |
| 명령 패턴 | 모든 플레이어 행동은 `Command` 객체 → `sim.enqueue(cmd)`. UI가 상태를 직접 바꾸지 않음 |
| 정수 연산 | 위치: 1칸 = 1000. 퍼센트: 1/10000 단위 정수(예: 25% = 2500). 체력·피해: 정수, 곱셈 후 `Math.floor` |
| 데이터 주도 | 수치는 `src/data/*.json`. 코드에 숫자를 박지 않는다 |
| 테스트 먼저 | 규칙 함수는 Vitest 단위 테스트부터. 마일스톤마다 Playwright 스크린샷 1장 이상 |
| 작은 커밋 | 작업 하나 끝날 때마다 커밋. 메시지: `M2-3 소환 명령과 경제` 형식 |
| 항상 초록불 | 커밋 전에 `npm test` + `npm run check` 통과 |

### 0.1 공통 완료 조건 (모든 마일스톤)

- [ ] `npm test` 통과 (단위 + 통합)
- [ ] `npm run check` 통과 (타입 검사 + 결정성 검사 + `python3 tools/gen_tables.py --check`)
- [ ] `npm run build` 성공, 번들 크기 기록
- [ ] Playwright로 실행 화면 스크린샷 (`docs/screens/M{n}.png`)
- [ ] README 체크리스트 갱신, 커밋·푸시

### 0.2 명령어 (M0에서 만듦)

| 명령 | 하는 일 |
|------|--------|
| `npm run dev` | 개발 서버 (브라우저에서 바로 플레이) |
| `npm test` | Vitest 전체 |
| `npm run check` | `tsc --noEmit` + `tools/check-determinism.mjs` + 데이터 검사 |
| `npm run build` | 프로덕션 빌드 (`dist/`) |
| `npm run e2e` | Playwright 스모크 테스트 + 스크린샷 |
| `npm run sim -- --seed 1 --deck base --mode infinite --bot greedy` | 화면 없이 한 판 자동 실행, 도달 단계 출력 (M11) |

## 4. 긴 개발 세션 진행 순서 (1시간 이상 연속 작업용)

한 세션에서 아래 순서대로 쉬지 않고 진행한다. 각 블록 끝에 테스트·커밋.

| 세션 | 범위 | 예상 | 끝났을 때 볼 수 있는 것 |
|------|------|------|----------------------|
| 세션 1 | M0 전체 → M1 전체 | 2~3시간 | 순환의 정원에서 몹이 돌고, 150마리 넘으면 패배 |
| 세션 2 | M2 전체 → M3-1~M3-5 | 3시간 | 소환·공격·승급이 되는 플레이 가능한 버전 |
| 세션 3 | M3-6~M3-12 → M4 | 4~5시간 | 기본 덱 25종 특색, 보스, 투명 몹까지 한 판 완주 |
| 세션 4 | M5 → M6 | 4시간 | 도전·강화·도박·미션, 두 모드 완성 |
| 세션 5 | M7 → M8 → M9 | 5시간 | 덱·해금·계정·타워 성장 |
| 세션 6 | M10 → M11 | 4~5시간 | 출석·업적·아트·튜토리얼·밸런스 시뮬레이터 |
| 세션 7 | M12 | 2시간 | 휴대폰 설치 + 자동 업데이트 + 아이폰 웹앱 |
| 세션 8 | M13 | 4시간 | 안드로이드 ↔ 아이폰 2인 플레이 |
| **합계** | | **약 30~35시간** | |

- 각 세션 시작 시: `git pull` → `npm ci` → `npm test`로 초록불 확인 → 이 문서의 다음 작업부터
- 막히면: 그 작업을 '보류'로 표시하고 다음 독립 작업으로 넘어간 뒤, 세션 끝에 보고
