# ART-1 프롬프트 수정 기록

사용자의 후속 지시가 HANDOFF.md의 "기존 prompt 그대로"보다 우선한다. `queue.json` 159개 prompt를 생성 전에 수정했다. 순번·파일명·이름·kind·manifest·코드는 유지한다. 원문은 기준 커밋 ca86c46에서 확인할 수 있고, 원문/수정문 SHA-256은 `prompt-audit.json`에 기록했다.

통통한 캐주얼 모바일 디펜스 그림체(chunky casual mobile defense style)의 작은 전투 유닛을 최우선 기준으로 삼았다. 큰 머리와 짧은 몸, 작은 점 눈, 단순한 입, 굵은 진갈색 선, 흙빛 단색 면, 많아야 그림자 한 단계를 명시했다. 기존 원문의 길고 날씬한 체형·발광·입자·잔장식·부하 군중 표현은 제거했다. 각성은 큰 무기·의상 덩어리로 구별하고, 성격과 주 장비·종족은 유지한다. 부하나 여러 마리의 동물은 단일 유닛 구성을 위해 단순 소품으로 묶었다. 인물 9명만 흉상이며 나머지는 전신이다.

공통 제출: Higgsfield `gpt_image_2_6`, 1:1, 1k PNG, medium, opaque. 흰 배경과 네 면 여백, 무기 끝·발까지 전부 포함, 글자·바닥·흰 스티커 테두리 금지. 참조 6장을 모두 육안으로 확인했으며, miner/icemage 2장은 외곽선과 단순화 기준으로 첨부한다. 별도 캐릭터에 두 참조 인물의 얼굴·복장을 복사하지 않도록 명시했다.

도구의 한 호출 상한은 6개다. 6개 요청 두 번으로 12개 묶음 단위로 제출·표시·검수한다. 대기 중에는 다음 묶음 제출을 병행했다. 원본 PNG는 tmp/chunky_raw, 작업 ID는 jobs.json에 기록한다.

## 기존 표시 경로 확인

현재 `src/art/characters/phaserArt.ts`의 `enemyCharacterTexture()`는 `look.rank === minion`일 때만 외부 적 WebP를 쓴다. 보스 19종은 절차 그림 경로가 우선하므로 해당 WebP를 바꿔도 전투 보스의 실제 표시가 자동으로 바뀌지는 않는다. 이 작업은 사용자 지시대로 코드를 수정하지 않고 에셋 159개와 기록만 바꾼다. 실제 보스 표시 경로 변경은 후속 코드 통합 검토 대상이다.

`src/ui/gallery/Gallery.ts`의 타워·적·인물 카드도 `ensureHumanTexture`·`ensureEnemyTexture`·`ensurePortraitTexture`로 절차 그림을 그린다. 인물 초상 역시 `portraits.ts`의 절차 그림 경로가 남아 있다. 따라서 갤러리 E2E의 통과는 새 WebP 159장의 실제 표시를 검증하지 않는다. 새 파일 자체는 PNG 원본 검수, 변환 후 밝은/어두운 배경 확인 그림, 파일별 해시·투명도 검사로 따로 확인한다. Claude는 후속 통합에서 외부 그림 표시 경로와 기존 표정·파츠 애니메이션을 함께 검토해야 한다.

## 재생성

159장 중 8장은 첫 결과를 제외하고 다시 생성했다. goldbattery는 여백과 납작한 색면, 유령·분열 슬라임·그림자 늑대는 불필요한 인간 복장·무기 제거, warrior/spearman/ninja/k9 각성은 네 면 여백을 강화했다. 몬스터 3장 재시도에만 승인한 단순 슬라임 결과를 참조했다. 제외한 작업과 이유는 rejections.json, 최종 선택 작업은 jobs.json에 기록했다.
