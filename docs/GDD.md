## 1. 개요

| 항목 | 내용 |
|------|------|
| 제목 | 운빨 디펜스 (가제) |
| 장르 | 랜덤 소환 + 3개 합성 타워 디펜스 |
| 세계관 | 앙숙인 아트라의 7종족(현대군·왕국·드워프·엘프·다크 엘프·오크·요정)이 외계 **암흑의 군주 녹스**와 녹스 군단(4천왕 → 대장 → 하수인)에 맞서 연합. 플레이어 = **연합군 총지휘관** ([STORY.md](STORY.md)) |
| 플랫폼 | 모바일 앱 (Android 우선, 세로 화면 9:16). 멀티 모드를 위해 아이폰은 웹앱(PWA)으로 함께 지원 |
| 이용 형태 | 1인 개인용, **완전 오프라인 플레이**. 인터넷은 업데이트 확인·다운로드에만 사용 |
| 게임 모드 | **캠페인**(테마 10개 × 50단계, 10단계마다 발판) / **무한 모드**(순환의 정원, 끝없이 강해짐) |
| 한 판 길이 | 캠페인 처음부터 약 51분 (발판에서 시작하면 더 짧음), 무한은 패배할 때까지 |
| 핵심 재미 | 소환하면 랜덤 타워 → 같은 타워 3개 → 다음 등급 랜덤 타워 1개. "이번엔 뭐가 나올까"의 운빨 |
| 수집 재미 | 타워 **65종**(일반 50 + 신 3 + 히든 12). 판마다 등급별 5종씩 **덱**을 짜서 출전 |
| 장기 성장 | 계정 레벨·특성·상점, 타워 해금·레벨·각성, 도감 보너스, 도박 숙련도, 업적, 출석, 일일·주간 미션 |
| 아트 | 2D SD 캐릭터. 공격하지 않을 때도 타워별 **대기 동작을 계속 반복** |
| 멀티 (예정) | 2인 협동·대결 (안드로이드 ↔ 아이폰). 1인용을 먼저 만들고, 멀티를 붙일 수 있게 구조를 미리 짬 ([MULTIPLAYER.md](MULTIPLAYER.md)) |

### 1.1 핵심 루프

```
[판 밖] 덱 편성 (등급별 5종) → 모드 선택
   ↓
[판 안] 돈 모으기 (몹 처치 / 일꾼 / 도전 / 미션 / 도박 / 경제형 타워)
   ↓
빈 칸 터치 → 소환 (100원, 덱의 노말 5종 중 랜덤)
   ↓
같은 타워 3개 → 승급 → 덱의 다음 등급 5종 중 랜덤 1개
   ↓
판 내 강화 · 특색 타워 배치 · 히든 조합
   ↓
더 강한 단계·보스·도전 버티기 → 더 많은 돈 → 반복
   ↓ (판 종료: 패배·클리어·포기)
[판 밖] 경험치·행운석·타워 조각 정산 → 레벨업·특성·상점·타워 성장 → 다음 판은 더 멀리
```

### 1.2 디자인 원칙

1. **운은 재미, 실력은 보험**: 결과는 랜덤이지만 덱 편성·배치·강화·돈 관리로 운의 편차를 줄일 수 있다.
2. **승급은 항상 이득**: 3개를 1개로 합쳐도 전투력이 오르도록 등급 배율을 3배보다 크게 잡는다.
3. **특색이 개성**: 같은 등급이라도 돈·버프·제어·확률 능력이 달라서 덱마다 플레이가 달라진다.
4. **오래 할수록 강해진다**: 판이 끝나도 무언가 남는다.
5. **오프라인 완결**: 서버 없이 모든 기능이 동작한다.
6. **미워도 함께**: 사이 나쁜 종족들이 힘을 합친다는 이야기를 시스템(종족 시너지·앙숙 경쟁·연합의 힘·우정 조합)으로 느끼게 한다.

### 1.3 참고한 흥행 요소 3가지 (1·2인용에 맞는 것만)

| # | 흥행 요소 | 장르 대표 사례 | 1인 적용 | 2인 적용 |
|---|----------|--------------|---------|---------|
| 1 | **매 판 다른 운 + 몇 초마다 하는 작은 선택** — 운이 나빠도 "한 판만 더" | 랜덤 소환·합성 디펜스 (랜덤 다이스 류) | 100원 소환 반복, 랜덤 승급 결과, 신 0.01%, 보스 카드 3장, 도박 | 서로의 운을 구경하는 재미, 우정 조합, 송금·선물 |
| 2 | **적이 정답을 요구하는 상성 퍼즐** — 특정 적은 특정 대응으로만 막힘 | 위장 적은 탐지 타워만 공격 (블룬스 TD 류), 물리 방어·마법 저항 적 (킹덤 러시 류) | 투명 몹 + 감지, 암흑 골렘(물리 저항)·수정 거북(마법 저항), **조합 편대 예고**, 원소 5종 | 역할 분담: 한 명은 감지·제어(진흙·얼음), 한 명은 화력 |
| 3 | **끝이 보이는 목표 + 끝없는 성장** — 지도에서 한 칸씩 나아가는 진행감과 영구 강화 | 스테이지 지도 + 별·업그레이드 (킹덤 러시 류) | **캠페인 10테마, 발판·발판 보상**, 계정·타워 성장, 도감 | 협동 캠페인에서 각자 발판 보상, 협동 업적 |

- 일부러 뺀 것: 뽑기 과금, 길드·랭킹·PvP 매칭, 시즌 패스, 광고 보상 — 1~2인 오프라인 개인용 게임에 맞지 않음

## 2. 게임 모드와 진행

### 2.1 모드 비교

| 항목 | 캠페인 | 무한 모드 |
|------|--------|----------|
| 맵 | 테마마다 전용 맵 10개 (테마 1 = 사거리 미로 13×13, 배치 96칸) — [CAMPAIGN.md](CAMPAIGN.md), [MAPS.md](MAPS.md) | 순환의 정원 (9×11, 배치 71칸) |
| 경로 | 3×3 블록 사이를 직각으로 돌아 출구로 (회전 5번 이상) | 사각 고리를 끝없이 순환 |
| 단계 | 테마당 0~50, **10단계마다 발판** (넘은 발판부터 다시 시작) | 0 ~ 무한 |
| 패배 조건 | **목숨 20개** 소진 (일반 몹 출구 도달 시 목숨 피해만큼 감소, 보스 출구 도달 즉시 패배) | 맵 위 살아 있는 몹 **150마리 초과** |
| 공통 패배 | 보스 제한시간 60초 초과 | 동일 |
| 종료 | 50단계 최종 보스 처치 = 테마 클리어 → 다음 테마 해금 | 패배할 때까지. **최고 단계 기록** |
| 보상 | 발판을 처음 넘을 때마다 계정 보상 | 기록 경신 경험치 |
| 해금 | 처음부터 (테마 1) | 캠페인 1-20 처음 클리어 |

### 2.2 한 판의 흐름

| 시점 | 내용 |
|------|------|
| 판 시작 | 시작 자금 1000원 (+계정 보너스), 일꾼 0명, 시작 타워(상점 구매 시) 배치 |
| 0단계 (60초) | 준비 시간. 몹 없음. 소환·배치 |
| 1단계~ | 60초마다 다음 단계. 일반 단계: 몹 20마리를 2.5초 간격으로 50초 동안 등장 → 10초 휴식 |
| 보스 단계 (10의 배수) | 보스 1마리만 등장 (+보스 패턴 소환 몹). 60초 제한, 처치 시 카드 선택 |
| 판 종료 | 결과 화면 → 계정 정산 ([PROGRESSION.md](PROGRESSION.md)) |

- 단계 타이머는 **보스가 살아 있어도 흘러간다**. 보스 단계 60초가 끝나는 순간 보스가 살아 있으면 패배
- 보스를 일찍 잡으면 남은 시간은 휴식 (다음 단계는 원래 시각에 시작)
- 앞 단계 몹이 남아 있어도 다음 단계 몹은 예정대로 등장 (몹이 쌓이는 압박)
- 팝업을 열어도 시간은 흐름 (⏸ 버튼으로만 정지)

### 2.3 몹 체력 곡선 (요약)

| 구간 | 단계당 체력 증가 | 비고 |
|------|----------------|------|
| 1~20 | ×1.151 | 1단계 체력 120 |
| 21~50 | ×1.08 | 50단계 체력 약 17,500 |
| 51~100 (무한) | ×1.06 | |
| 101~ (무한) | ×1.05 | 방어력 단계당 +0.5% (최대 60%) |

- 몹은 체력 외에 **방어력·마법 저항·속도·상태이상 저항**을 가지며 단계에 따라 오름. 35단계부터 **투명 몹** 등장
- 몹 종류·보스·등장 구성은 [ENEMIES.md](ENEMIES.md), 계산표는 [BALANCE.md](BALANCE.md)

## 3. 경제

| 항목 | 값 |
|------|-----|
| 시작 자금 | **1000원** |
| 소환 비용 | **100원 고정** (상점 할인 최대 -25원) |
| 일반 몹 처치 | **+10원**, 10단계마다 +1원 (10단계부터 11원 … 50단계 15원) |
| 보스 처치 | **+200원** + 효과 카드 3장 중 1장 |
| 일꾼 | 300원에 고용, 1명당 **5초마다 +5원** (분당 60원), **최대 10명** |
| 도전 | 6장 |
| 판 안 미션 | 8장 (일반 30개 보상 합계 17,000원) |
| 도박 | 7.2 |
| 경제형 타워 | 광부·상인·은행가·연금술사·포병 대장·재벌 등 ([TOWERS.md](TOWERS.md)) |

- 보유금 상한 없음. 표시는 1만 이상부터 `1.2만`, `3.4억`처럼 축약
- 일꾼은 판이 끝나면 사라짐. 일꾼 수입은 일시정지 중 멈춤

### 3.1 보스 효과 카드 (풀 12장 중 3장 랜덤)

| 카드 | 효과 | 등급 |
|------|------|------|
| 전군 강화 | 모든 타워 공격력 +20% (이번 판 영구) | 일반 |
| 긴급 자금 | 즉시 500원 × 보스 번호 (10단계 500 … 50단계 2,500) | 일반 |
| 행운의 소환 | 다음 소환 5회는 레어로 등장 | 일반 |
| 일꾼 열정 | 일꾼 수입 2배 (이번 판 영구, 중복 시 3배·4배) | 일반 |
| 대지진 | 현재 맵 위 몹 전체 체력 -30% | 일반 |
| 소환 할인 | 소환 비용 -20원 (이번 판 영구, 최소 50원) | 일반 |
| 끈끈이 | 몹 이동속도 -15% (이번 판 영구, 최대 -45%) | 일반 |
| 무료 일꾼 | 일꾼 +2명 (최대 수 무시) | 일반 |
| 승급의 축복 | 다음 승급 3회는 결과 2개 중 선택 | 희귀 |
| 쌍둥이 소환 | 30초 동안 소환하면 같은 타워 2개 (빈 칸이 있을 때) | 희귀 |
| 신의 눈길 | 이번 판 신 타워 확률 ×3 | 희귀 |
| 황금 손 | 이번 판 모든 돈 획득 +25% | 희귀 |

- 제시되는 카드 1장마다 15% 확률로 희귀 카드. 같은 판에서 같은 카드를 다시 고를 수 있음
- 계정 상점 '보스 카드 선택지'를 사면 4장 중 선택

| 레어 | 파랑 | ★★ | 노말 3 승급 | ×3.5 | 35 |
| 유니크 | 보라 | ★★★ | 레어 3 승급 | ×12 | 120 |
| 히어로 | 주황 | ★★★★ | 유니크 3 승급 | ×40 | 400 |
| 레전드 | 빨강 | ★★★★★ | 히어로 3 승급 | ×140 | 1,400 |
| **신** | 무지개 | 👑 | 소환·승급 시 **0.01%** | ×600 | 6,000 |
| **히든** | 검정+금 | 💠 | 조합식 | ×300 | 3,000 |

- **승급은 항상 이득**: 노말 3개(30) → 레어 1개(35)처럼 승급할 때마다 전투력이 약 11~17% 오르고 칸 2개가 빈다
- 기준 DPS는 '공격형 타워' 기준. 특색 타워는 공격력이 기준의 50~80%이고 대신 고유 능력을 가짐

### 4.2 타워 수와 덱 편성

- 타워 풀: **노말 10 · 레어 10 · 유니크 10 · 히어로 10 · 레전드 10 = 50종** + 신 3 + 히든 12 = **총 65종**
- 판 시작 전 **덱**을 편성한다: **등급별 5종씩, 총 25종**
  - 소환: 덱의 노말 5종 중 균등 랜덤
  - 승급: 덱의 다음 등급 5종 중 균등 랜덤
  - 신 타워: 덱과 무관하게 0.01% (3종 중 균등 랜덤)
  - 히든 타워: 재료가 **모두 덱에 있어야** 만들 수 있음 → 덱 짜기의 핵심 전략
- 등급별 5종으로 제한하는 이유: 종류가 많을수록 같은 타워 3개가 모이기 어려워진다. 전체 종류는 늘리고, 한 판에 쓰는 종류는 5종으로 유지해 승급 속도를 지킨다
- **특색 최소 수 규칙** (덱 저장 시 검사): 노말 ≥1 · 레어 ≥2 · 유니크 ≥3 · 히어로 ≥4 · 레전드 5 (레전드는 전부 특색)
- 풀 안의 특색 타워 수: 노말 2 · 레어 4 · 유니크 6 · 히어로 8 · 레전드 10
- 덱 프리셋 3개 저장, [추천 편성] 버튼, [랜덤 덱] 버튼 (랜덤 덱으로 시작하면 경험치 +20%)
- 덱 편성 경고 (저장은 가능): ① **감지 타워가 0종** → "35단계부터 투명 몹이 나와요" ② 물리 또는 마법 타워만 있음 → "암흑 골렘/수정 거북을 잡기 어려워요"
- 덱에 넣으려면 **해금**되어 있어야 함. 처음에는 기본 25종(= 기본 덱) 해금. 나머지 25종은 조각 10개로 해금 ([PROGRESSION.md](PROGRESSION.md))

### 4.3 소환

- 경로가 아닌 **빈 배치 칸**을 터치하면 100원으로 그 칸에 소환 (설정에서 '두 번 터치 소환'으로 변경 가능)
- 1칸에 타워 1개
- 소환 판정 순서: ① 신 타워 0.01% (+보정) → ② 레어 직행 확률(행운의 여신·특성·카드) → ③ 덱 노말 5종 균등
- 돈 부족: 칸이 흔들리고 "100원이 필요해요" 토스트
- 배치 칸이 가득 참: "빈 칸이 없어요 — 승급으로 칸을 비워 보세요" 토스트

### 4.4 승급

- 조건: **같은 종류 + 같은 등급** 3개 보유 (위치 무관)
- 타워를 터치 → [승급] 버튼 (3개 이상일 때 활성화, 버튼에 보유 수 "3/3" 표시)
- 결과는 **터치한 타워 자리**에 생성. 함께 사라지는 2개는 같은 종류 중 **가장 나중에 소환된 2개**
- [모두 승급]: 터치한 타워와 같은 종류를 가능한 만큼 연속 승급 (예: 7개 → 승급 2회, 1개 남음)
- 결과: 덱의 다음 등급 5종 균등 랜덤. 승급마다 신 타워 0.01% 판정
- **레전드 3개는 승급 불가** (히든 재료로 사용)
- 승급하면 그 타워에 쌓여 있던 판 내 스택(광전사 공속, 무한의 검 공격력 등)은 초기화

### 4.5 이동과 교환

- 타워를 **길게 눌러 끌면** 빈 칸으로 이동, 다른 타워 위에 놓으면 **자리 교환** (무료, 쿨타임 없음)
- 오라형 특색(북치기·음유시인·대장장이·수호 기사)의 효과 범위를 맞추는 핵심 조작
- 이동 중인 타워는 0.5초 동안 공격하지 않음

### 4.6 종족 시너지·앙숙·원소 (요약, 상세는 [TOWERS.md](TOWERS.md) 8장)

| 시스템 | 규칙 |
|--------|------|
| 종족 시너지 | 판 위에 같은 종족의 **서로 다른 타워 종류**가 3/5/7종(요정은 2/4/6)이면 단계별 보너스 |
| 연합의 힘 | 7종족이 모두 판 위에 있으면 전체 공격력 +15% |
| 앙숙 경쟁 | 앙숙 종족 타워가 주변 8칸에 붙어 있으면 둘 다 공격속도 +8% (엘프↔다크 엘프, 드워프↔엘프, 오크↔왕국, 현대군↔요정) |
| 원소 | 🔥화염 = 범위 (화염 마법사는 + 화상 3초) · ⚡번개 = 연쇄 · ☠독 = 5초 서서히 중독 · ❄얼음 = 빙결(일시 정지) · 🟫진흙 = 둔화. 원소는 타워 분류(대표 효과)이고, 실제 효과는 각 타워의 공격 형태·지속 피해(dot)·특색 데이터가 정한다 — 용 소환사·대마법사는 화염이지만 화상 없이 범위 + 자기 특색 |

### 4.7 히든 조합

- 재료 타워가 **판 위에 모두** 있을 때, 재료 중 하나를 터치하면 [조합] 버튼 표시
- 결과는 터치한 칸에, 나머지 재료는 사라짐
- 조합식은 처음엔 "???". 한 번 만들면 도감에 영구 공개. 계정 Lv10마다 힌트 1개
- 조합식 전체는 [TOWERS.md](TOWERS.md)

| 우선순위 | 설명 | 기본 사용 |
|---------|------|----------|
| 선두 | 경로 진행도가 가장 큰 몹 (무한 모드는 가장 오래 살아 있는 몹) | **대부분 타워 기본값** |
| 최대 체력 | 현재 체력이 가장 높은 몹 | 저격수 |
| 보스 우선 | 보스·도전 보스가 사거리 안에 있으면 우선 | 그림자 암살자, 독 궁수 |
| 무표식 | 표식이 없는 몹 우선 | 정찰병 |
| 최저 체력 | 처치 가능성이 높은 몹 | 상인 |

- 타워별 우선순위 변경은 계정 Lv8 해금

### 5.4 피해 공식

타워의 피해는 **물리 · 마법 · 고정** 세 종류다. 몹은 **방어력**(물리를 막음)과 **마법 저항**(마법을 막음)을 가진다.

```
1회 피해 = 물리 공격력 × 배율 × (1 − 방어 감소율)
         + 마법 공격력 × 배율 × (1 − 마법 감소율)
         + 고정 피해  × 배율                         ← 고정 피해는 아무것에도 막히지 않음

배율 = (1 + 공격력% 합)                 ← 판 내 강화, 타워 레벨, 특성, 버프, 카드, 도감 보너스 (전부 더함)
     × 치명타 배율 (치명타일 때)          ← 기본 ×2, 타워에 따라 ×3, 판 내 '치명타 피해' 강화로 증가
     × (1 + 받는 피해 증가% 합)          ← 용 소환사 화염, 빙결, 차원술사 각성 등 몹에 걸린 약화
     × 보스 피해 배율 (대상이 보스일 때)   ← 그림자 암살자, 특성 '거인 사냥꾼'

방어 감소율 = A ÷ (A + 100)
A = max(0, 방어력 × (1 − 방어 관통 합) − 고정 방어 관통)
방어 관통 합 = 타워 방어 관통 + 판 내 '물리 관통 강화' + 상점 영구 관통 + 표식·약화 효과   (최대 90%)
마법 감소율도 같은 식 (마법 저항, 마법 관통)
```

| 방어력(관통 후) | 0 | 25 | 50 | 100 | 200 | 300 |
|---------------|---|----|----|-----|-----|-----|
| 피해 감소 | 0% | 20% | 33% | 50% | 67% | 75% |

| 규칙 | 값 |
|------|-----|
| 공격력% | 모두 더한 뒤 한 번 곱함 (합연산) |
| 공격속도% | 모두 더함. 최종 공속 = 기본 공속 × (1 + 공속% 합), **최대 기본의 5배**, 그리고 **초당 15회**를 넘지 않음 |
| 치명타 확률 | 기본 0% + 타워 + 강화 + 특성, 최대 100% |
| 방어 관통·마법 관통 | 각각 최대 90% |
| 독·화상·출혈 | 고정 피해 (방어 무시), 치명타 없음 |
| 피해 숫자 | 물리 흰색 · 마법 하늘색 · 고정 노란색 · 치명타 크게. 설정에서 끔/켬 |

### 5.5 상태 이상

| 상태 | 효과 | 중첩 | 보스 |
|------|------|------|------|
| 둔화 (진흙 등) | 이동속도 -x% | 가장 강한 것만, 최대 70% | 효과 절반 (최대 35%) |
| 기절 | 이동 정지 | 지속시간 갱신 | 지속시간 30% |
| 정지(시간) | 이동·회복·능력 정지 | 갱신 | 지속시간 30% |
| 빙결 (얼음) | 일시 정지 + 받는 피해 +10% | 갱신 | 지속시간 30% |
| 되돌리기 | 출발 지점으로 이동 | — | 면역 |
| 화상 | 초당 공격력의 30% × 3초 | 최대 3중첩 | 적용 |
| 독 | 초당 공격력의 50% × 5초 | 최대 5중첩 | 적용 |
| 표식 | 방어력 감소 | 가장 강한 것만 | 적용 |
| 약화 | 받는 피해 +x% | 서로 다른 출처는 합산, 최대 +100% | 적용 |

- 기절·정지·빙결이 끝난 직후 **1초 동안 행동 불가 면역** (무한 정지 방지)

### 5.6 지원 효과 (오라·버프)

- **같은 타워의 지원 효과는 중첩되지 않음** (학자 2개 = +20%만). **서로 다른 타워의 효과는 중첩**
- "주변 8칸" = 자신을 둘러싼 3×3 (자신 제외). "주변 24칸" = 5×5 (자신 제외)
- 범위형 지원은 자기 자신에게 적용되지 않음. "전체" 효과는 자신 포함
- 사거리 안 몹에 거는 오라(수호 기사 둔화 등)는 사거리 밖으로 나가면 0.5초 뒤 해제

### 5.7 투명과 감지

| 항목 | 규칙 |
|------|------|
| 투명 몹 | 35단계부터 투명 도둑, 70단계부터 그림자 늑대, **40단계 보스 망령 군주는 항상 투명** ([ENEMIES.md](ENEMIES.md) 5장) |
| 드러나지 않은 투명 몹 | 대상 지정 불가 + 광역·연쇄·전체·상태이상·지속 피해 **모두 무효** |
| 👁 감지 오라 | 반경 안의 투명 몹을 '드러남' 상태로 → **모든 타워**가 공격 가능. 오라를 벗어나면 0.5초 뒤 다시 투명 |
| 👁 감지(자신) | 그 타워만 투명 몹을 공격 가능 |
| 감지 타워 | 정찰병(레어), 점성술사(유니크), 예언자(히어로), 그림자 암살자(레전드), 천상의 궁수·운명의 예언자(히든) = 오라 / 바람 궁수, 저격수, 차원술사, 운명의 신 = 자신 ([TOWERS.md](TOWERS.md) 9장) |
| 결과 | 감지 없이는 40단계 보스를 잡을 수 없음 → **높은 단계에서 감지 타워는 필수** |
| 안내 | 덱에 감지 타워가 없으면 덱 편성 경고, 판 위에 감지가 없는데 투명 몹이 나오면 경고 배너 |

## 7. 강화와 도박 (판 안)

하단 **[강화]** 탭. 위쪽은 타워 강화, 아래쪽은 도박.

### 7.1 판 내 강화 (이번 판 동안 유지)

강화 시트는 탭 2개: **[등급 강화]** (등급군별 공격력) / **[능력치 강화]** (모든 타워 공통). 후반에는 공속·관통을 몰아 올려 타워가 **엄청 빠르게** 공격하는 플레이가 가능하다.

**등급 강화** (해당 등급군의 현재·미래 타워 모두)

| 강화 | 대상 | 효과/Lv | 최대 | 비용 (Lv → Lv+1) |
|------|------|--------|------|-----------------|
| 일반 강화 | 노말·레어 | 공격력 +10% | 50 | 50 + 50 × Lv |
| 영웅 강화 | 유니크·히어로 | 공격력 +10% | 50 | 200 + 100 × Lv |
| 전설 강화 | 레전드·신·히든 | 공격력 +10% | 50 | 500 + 250 × Lv |

**능력치 강화** (모든 타워)

| 강화 | 효과/Lv | 최대 | 최대치 효과 | 비용 (Lv → Lv+1) |
|------|--------|------|-----------|-----------------|
| ⚡ 공격속도 | +4% | 50 | +200% | 100 + 60 × Lv |
| 🗡 물리 관통 (방무) | +2% | 30 | 60% | 150 + 100 × Lv |
| 🔮 마법 관통 | +2% | 30 | 60% | 150 + 100 × Lv |
| 💥 치명타 확률 | +1%p | 30 | +30%p | 100 + 80 × Lv |
| 💢 치명타 피해 | +10%p | 30 | +300%p (×2 → ×5) | 100 + 80 × Lv |
| 🎯 사거리 | +2% | 10 | +20% | 300 + 200 × Lv |

**초월 강화** (무한 모드용, 등급 강화 3종이 모두 Lv50이 되면 열림)

| 강화 | 효과/Lv | 최대 | 비용 |
|------|--------|------|------|
| 초월 공격력 | 모든 타워 공격력 +5% | 없음 | 50,000 × 1.15^Lv |

| 한도 | 값 | 이유 |
|------|-----|------|
| 최종 공속 | 기본의 **5배**, 초당 최대 **15회** | 공속 강화 +200% + 버프(전쟁 군주 30%·음유시인 25%·북치기 15%·축제의 왕 30%) + 상점·특성으로 5배까지 도달 가능 |
| 방어 관통 | 90% | 관통 강화 60% + 타워 관통 + 표식 |
| 치명타 확률 | 100% | |

- 학자 각성 시 모든 강화 비용 -20%
- 버튼을 길게 누르면 돈이 허락하는 만큼 연속 강화
- 공속이 매우 빨라지면: 공격 애니메이션 재생 속도는 최대 3배까지만 빨라지고, 그 이상은 잔상 이펙트로 표현 ([ART.md](ART.md))

### 7.2 도박

| 테이블 | 비용 | 결과 범위 | 해금 |
|--------|------|-----------|------|
| 10원 | 10 | 0 ~ 50원 | 기본 |
| 100원 | 100 | 0 ~ 500원 | 기본 |
| 1000원 | 1,000 | 0 ~ 5,000원 | 계정 Lv7 |
| 10000원 | 10,000 | 0 ~ 50,000원 | 계정 Lv20 |

| 배율 | 기본 확률 |
|------|----------|
| ×0 | 40% |
| ×0.5 | 20% |
| ×1 | 21% |
| ×2 | 11% |
| ×3 | 6% |
| ×5 | 2% |

- 기본 기대값 약 91% — **잭팟 게이지까지 넣은 실제 기대값** (긴 판 평균: 받은 돈 ÷ 낸 돈). 표만의 기대값(Σ 배율 × 확률)은 81%이고, 평균 26번에 한 번 오는 잭팟(×3·×5를 6 : 2, 평균 ×3.5)이 약 10%p를 더한다. 슬롯 연출 1초 (숙련도 Lv5부터 건너뛰기·10연속)
  - (M5 검토 반영: 처음 표 ×1 15%·×2 15%·×3 7%·×5 3%는 표만 91%라 잭팟을 넣으면 약 101% — 계정 첫 판부터 도박이 이득이었다. 숫자는 `src/data/game.json` gamble)
- **잭팟 게이지**: ×0이 나올 때마다 +1, 10칸이 차면 다음 도박 ×3 이상 확정
- 도박꾼(유니크)·특성 '대박 기운'·도박 숙련도로 확률이 바뀜 ([PROGRESSION.md](PROGRESSION.md))
