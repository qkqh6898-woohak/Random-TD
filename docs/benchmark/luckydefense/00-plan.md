## 4. 조사 원칙

1. **숫자를 지어내지 않는다.** 출처에서 확인한 값만 적고 표마다 출처를 단다.
2. 출처끼리 값이 다르면 **함께 적는다.**
3. 찾지 못한 값은 **미확인**으로 비워 둔다. 출처에 규칙이 명시된 경우만 계산해 채우고 **계산값**으로 표시한다.
4. 같은 회사의 다른 게임(운빨 IP 후속작 등) 정보가 섞이지 않게 표시한다.
