# 운빨존많겜(Lucky Defense / OMFG Lucky Me!) 유물(Relic·Artifact) 시스템 조사

- 조사일: 2026-11-23
- 대상: 111퍼센트 '운빨존많겜'. 국내 출시 2024-05-23(나무위키(검색요약)). 영문판 명칭은 **Lucky Defense**이고, 커뮤니티 영문 자료는 유물을 **Artifact**로 부른다.
- 명칭 메모: iOS 스토어(App ID 6482291732) 영문 제목은 **"OMFG Lucky Me!"**(AppBrain, 마지막 업데이트 2025-08-08로 표기됨). Dudcode는 현재 이름을 "What the Luck?: CoOp Defense"(구 Lucky Defense)라고 적었고, Discord 목록에도 "What the Luck?"이 별칭으로 나온다. 다만 이 개명을 확인해 주는 111% 공식 공지는 찾지 못했다. **같은 회사의 다른 게임과 이름이 겹칠 수 있으니, Dudcode 계열 정보는 '혼입 가능'으로 표시했다.**

## 0. 조사 환경과 한계 (먼저 읽기)

- 이 세션에서는 **WebFetch/curl로 외부 사이트 본문을 열 수 없었다.** thewiki.kr, en.namu.wiki, bluestacks.com, grindnstrat.com, note.com, luckydefenseguides.com, gall.dcinside.com, reddit.com, web.archive.org 모두 프록시 단계에서 막혔다. 그래서 대부분의 수치는 **웹검색 결과 요약에 인용된 원문 조각**에서 가져왔다. 출처 표기 형식은 "사이트명(검색요약)"이다.
- 예외: **GitHub 공개 저장소 `GhidBase/lucky-defense-guides-legacy`**(luckydefenseguides.com의 구버전 정적 사이트, 마지막 커밋 2025-11-07)는 git clone으로 원문 전체를 직접 읽었다. 출처 표기는 "LDG(원문)"이다.
- 웹검색 호출 한도(세션 공용 200회)가 조사 도중 소진되어 추가 검색을 할 수 없었다. 미확인 항목은 후속 요청으로 이어서 찾을 수 있다.
- 나무위키 수치는 판본(r1, r394~r992 등)이 섞인 검색요약이다. 판본 간 차이가 확인된 곳은 따로 적었다.

- **금고**: LDG(원문) "Safe Box Earnings" 표(100코인으로 시작해 80웨이브 동안 금고 이자만 받는 가정)가 Lv1~Lv11 전 구간에서 `100×(1+r)^80`, `r = 5% + 0.5%×(Lv−1)`과 ±1코인 이내로 맞는다. 직접 검산했다.
- **머니건**: LDG(원문) 스크린샷 문구 "Increases the ATK by 0.91% of held coins"는 0.7+0.07×3, 즉 Lv4 값이다. 또 LDG(원문) Awakened Hailey 비교표에서 `필요 골드 × (0.7+0.07×(Lv−1))%`가 Lv1~10에서 약 1,995로 일정하다. Lv11은 1,960으로, 140k가 반올림된 값으로 보인다.
- **Lv6 값 대조**: LDG(원문) 룰렛 시뮬레이터에 적힌 "level 6 artifacts" 값 가운데 해골석 15%, 승부사의 손목 15%, 나팔 7.5%, 영수증 4.5%가 공식과 일치한다. **황금 주사위만 4.2%로 적혀 있어** 공식값 4.5%와 다르다(아래 표에 따로 표시).

## 8. 기획 분석 메모 (출처 기반 정리, 해석 포함)

- **경제 → 전투 전환 루프**: 금고(보유 코인에 복리 이자)와 머니건(보유 코인에 비례한 공격력)이 "쓰지 말고 쌓아라"는 하나의 축을 만든다. 금고 Lv1→Lv11에서 80웨이브 복리 결과는 약 41배 차이 난다(4,956 → 204,840, LDG). 레벨 1당 체감 차이가 커서 난이도 진입 기준이 사실상 이 두 유물의 레벨로 정해진다(게임오릭션·나무위키·LDG가 공통으로 서술).
- **수집형 31종 균등 뽑기와 지정 구매(800다이아)**: 31종 균등 1/31 드롭(커뮤니티 계산) 때문에 핵심 2종을 얻으려는 리세마라·지정 구매 수요가 생긴다. 신규 퀘스트에서 금고·머니건을 직접 주는 설계(LDG)는 이 마찰을 줄이는 장치로 보인다(해석).
- **정수형 효과의 반올림으로 생기는 '사실상 만렙'**: 램프 6, 고기·성벽 10, 행운석 6/11 단계처럼, 레벨업해도 체감 효과가 없는 구간이 생긴다.
