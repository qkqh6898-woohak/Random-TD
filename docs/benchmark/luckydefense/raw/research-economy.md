# 운빨존많겜 재화 체계와 BM 흐름 조사

- 대상: 운빨존많겜 (111퍼센트, 2024-05-23 출시). 글로벌 명칭 Lucky Defense! → What the Luck?: Lucky Defense / What the Luck?: CoOp Defense → OMFG Lucky Me!
- 조사일: 2026-11-23
- 조사 방법: 이 세션에서는 WebFetch와 curl로 외부 사이트를 열 수 없었다(sensortower.com, apps.apple.com, news.bizwatch.co.kr 모두 DNS 단계에서 막힘). 그래서 **모든 내용은 WebSearch 결과 요약(검색 엔진이 원문을 발췌·요약한 텍스트)에 기반**한다. 원문 표나 이미지는 직접 보지 못했다. 검색 한도(세션 공유 200회)에 도달해 r/LuckyDefense, 인벤 게시판, thewiki, superwiki는 확인하지 못했다.
- 표기 규칙
  - **[확인]**: 기사, 스토어, 공식 공지 등에서 수치를 확인함(검색 요약 경유)
  - **[커뮤니티]**: 디시, 아카라이브, 블로그 등 유저 자료
  - **나무위키(검색요약)**: namu.wiki는 열 수 없어 검색 요약에 나온 내용만 사용
  - **[추정]**: 내가 계산한 값. 근거를 함께 적음
  - **미확인**: 찾지 못한 값
- 버전 주의: 커뮤니티 수치 대부분은 2024년 7월~2025년 말 자료다. 2026년 11월 현재 값과 다를 수 있다.

## 7. 쿠폰과 이벤트 운영 패턴

### 7.1 쿠폰

- 입력 경로(KR): 우측 상단 메뉴 → 설정 → 쿠폰 등록. 대소문자를 구분한다. iOS는 정책상 게임 내 입력이 막힐 수 있어 웹 입력 경로가 있다는 언급이 있다[gametrends, LDPlayer, BlueStacks KO 검색요약].
- 배포 채널: KR은 공식 네이버 카페, SNS, 이벤트 페이지. 글로벌은 **Discord(유물 스크린샷 인증 절차 후 공개)**[pocketgamer].
- 글로벌 코드 예시(pocketgamer, 2026-11 갱신본): LUCKYDISCORD, LUCKYCOMMU50K(5,000 Gems), LUCKYJOIN30K(3,000 Diamonds), LUCKY10KFANS(1,000 Diamonds). 커뮤니티 규모 달성을 기념하는 코드명이고, 만료가 빠르다.
- KR 예시: LUCKY100(신화 영웅 1 + 다이아 2,000, 2024-12까지로 기재. nomadlee, 저신뢰).
- **오프라인 연계 쿠폰**이 핵심 패턴이다. 팝업 참가자 전원에게 인게임 재화 쿠폰을 주고, 굿즈 구매 시 한정 스킨 쿠폰을 준다. 이런 쿠폰이 중고나라와 당근에서 "팝업 특별스킨 + 10,000 다이아 쿠폰"으로 재판매된다.
