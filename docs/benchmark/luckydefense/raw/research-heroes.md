# 운빨존많겜 (Lucky Defense → OMFG Lucky Me!) — 캐릭터 · 레벨업 · 특성(패시브 성장) 조사

- 조사일: 2026-11-23
- 개발/서비스: 111퍼센트(111%). 지주사는 슈퍼패스트.
- **조사 방법과 한계 (먼저 읽을 것)**
  - 이 세션에서는 WebFetch가 ghidbase.github.io와 pocketgamer.com 모두 DNS 단계에서 차단됐다(네트워크 허용 목록 밖). 그래서 **모든 수치는 WebSearch 결과 요약(검색 엔진이 원문 페이지를 요약한 것)으로 확인한 값**이다. 원문 페이지를 직접 열어 대조하지 못했다.
  - cafe.naver.com과 namu.wiki도 열지 못했다. 나무위키 내용은 모두 **'나무위키(검색요약)'**으로 표기했다.
  - 조사 도중 WebSearch 호출 한도(턴당 200회, 공유)가 소진됐다. 그래서 신화 전체 목록, 등급별 유닛 수, 기본 소환 확률 등 일부 항목은 '미확인'으로 남겼다.
  - 혼동 주의: 같은 회사의 '운빨돌격대(Lucky Offense)'는 다른 게임이다. dcinside `luckyheroes` 갤러리는 '운빨IP 마이너 갤러리'로 여러 운빨 게임을 함께 다룬다. 이 문서에서는 내용(펫, 군체 타르 등)으로 운빨존많겜 공지임이 확인되는 글만 인용했다.
  - 용어 대응: 한국판 등급 '영웅' = 영문판 'Epic'. '신화석' = Mythic Stone(영문 가이드에 따라 Shard로도 표기).

### A-3. 핵심 루프

**판 안 (1판)**
1. 코인(또는 스크롤)으로 무작위 유닛을 **소환**한다. (PocketGamer guide, 검색요약)
2. 같은 유닛 3개를 **합성**하면 한 등급 위 무작위 유닛이 된다. 영웅(Epic) 이하에 적용되며 일반 → 희귀 → 영웅 → 전설 순이다. (PocketGamer guide, luckydefenseguides, 검색요약)
3. **도박(운빨 소환)**: 행운석을 써서 희귀·영웅·전설 유닛을 확률로 뽑는다. 등급이 오를수록 확률은 낮고 비용은 높다. (나무위키 검색요약)
4. 쓰지 않는 유닛을 **판매**하면 행운석을 받는다. (PocketGamer guide)
5. 레시피 재료가 필드에 모이면 **신화를 조합**한다(신화 탭에서 '필요 영웅 필드 표시' 옵션 제공). 불멸은 신화에서 개별 조건을 채우면 변신한다.
6. **판 안 강화**: 코인으로 일반~희귀·영웅 유닛을, 행운석으로 전설~신화 유닛의 능력치를 강화한다. (나무위키 검색요약)
7. 미션을 클리어하면 행운석을 준다(유물로 증가). (나무위키 검색요약)

**판 밖 (메타 성장)**
- 신화 해금(다이아) → 신화석+골드로 신화 레벨업(최대 15) → Lv10에 보물 제단 해금 → Lv15에 불멸 해금 → 불멸은 불멸석으로 성장(2주년부터 최대 25, 돌파석 사용)
- 비신화 유닛 영구 레벨업(중복 카드+골드)
- 유물 31종(최대 Lv11), 보물(제단), 펫(계정 Lv9 해금, 종합 레벨)

### B-3. 신화 영웅

**해금**
- 기본 신화 '닌자'는 무료다. 나머지 일반 신화는 **3,000 다이아**에 해금한다. **고급 신화**는 난이도 80웨이브를 클리어해야 구매할 수 있다. (begchi.com 블로그, 600~900일 전 작성 / 신뢰도 중)
- 프롬프트의 '해금 비용 신화석'은 확인하지 못했다. 확인된 해금 재화는 다이아다.

### D-5. 기획 관점 요약
- 판 안 성장은 **랜덤 소환 → 3합성 → 도박 → 레시피 신화 → 불멸 변신**의 확률 사다리다. 판 밖 성장은 이 사다리의 **확률(유물), 경제(행운석/골드 유물, 보물 상한), 개별 유닛 성능(신화 레벨 마일스톤)**을 영구로 끌어올린다.
- 신화 레벨업 비용은 Lv6(115석) → Lv12(1,055석) → Lv15(2,155석)로 급격히 오른다. 고유 강화가 걸린 **Lv6·Lv12**가 주요 결제·재화 소모 구간이다. Lv10(제단)과 Lv15(불멸 해금, 6,000다이아 추가)는 새 시스템을 여는 관문이다.
- '특성 트리' 같은 선택형 패시브는 확인되지 않았다. 패시브 성장은 모두 **수집·레벨형**(유물 31종 Lv11, 보물 1슬롯 랜덤 옵션 + 강화 확률, 펫 종합 레벨)이다.
