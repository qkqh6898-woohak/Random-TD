## 0. 그림 출처 (HF-2부터)

**함께 넣은 힉스필드 그림이 먼저, 코드로 그린 절차 그림은 대체.** 모든 그림은 `public/assets/`에 들어 있어 오프라인으로 돈다 (한 파일 빌드는 data URI로 품음, 주소는 `src/assets.ts assetUrl`).
그림 파일이 없거나 못 받으면 예전처럼 코드가 그린 그림이 그 자리를 채운다 (게임은 그대로 돈다).

| 무엇 | 파일 | 쓰는 곳 | 대체 |
|------|------|---------|------|
| 타워·각성·적·인물 캐릭터 | `assets/characters/<id>.webp` · `<id>_awaken` · `enemy_<id>` · `person_<id>` (+ `manifest.json` 목록) | 맵 위 타워·몹, 정보 패널·캐릭터 카드 초상 (Boot.preload에서 모두 받음) | 절차 파츠 그림 (`src/art/characters/`) |
| 전투 배경 | `assets/backgrounds/bg_tTT_bB.webp` (테마 10 × 하늘 밴드 5, 720×1280) | Game 장면 맨 아래, 지금 화면(가로 1080 × 세로 1920~2600, T-3)을 덮게 + 넓은 화면 양옆 띠에 흐리게 (`BattleBackground`) | 절차 풀밭 (`MapRenderer` 배경) |
| 보스 컷인 | `assets/cutins/cutin_<보스 id>.webp` (19종) | 단계 보스 등장 DOM 컷인 (`ui/cutin/BossCutin.ts`) | 컷인 없음 (보스 이름표 배너만) |
| 타이틀 | `assets/title/title_keyart_1·2.webp` | 타이틀 화면 뒤 (켤 때마다 하나) | 절차 타이틀 (하늘·성벽·대기 동작 타워) |

### 0.1 캐릭터별 화면 크기

- 사용자 요청: **"캐릭터 크기는 다 다르게 설정하고 꼭 칸에 안 맞춰도 돼."** → 캐릭터마다 크기 배수 `scale`을 `src/data/characterLooks.json`에 적는다 (각성은 `awaken.scale`, 적도 모두). 범위 0.6~1.6 (`gen_tables.py --check`·로더 검사).
- 초기값 = 몸집 + 등급 덤: 요정 ~0.8 · 고블린·드워프 ~0.9 · 사람·엘프 ~1.0 · 중갑·오크 ~1.1 · 골렘·정령 ~1.25 · 신 ~1.4 (+ 레어 0.03 · 유니크 0.06 · 히어로 0.09 · 레전드 0.12 · 신 0.15), 각성 +0.05.
  적: 하수인 0.82~1.1, 대장 1.0~1.2, 4천왕 1.2~1.28, 군주 1.32 — 몸집 분류(소형·중형·대형·보스) 크기에 곱하고 지름 상한 1.6칸.
- 캐릭터는 칸 밖으로 삐져나와도 된다 (예전의 칸 너비 맞춤 제거, 아주 넓은 그림만 약 1.6칸으로 줄임). **누르는 자리는 칸 그대로**, 아래 줄이 위에 그려진다 (깊이 = 발밑 y).
- 절차 대체 그림도 같은 배수를 쓴다.

### 0.2 전투 배경 고르기 (`src/view/artBand.ts`, 설정 `game.json art`)

- 캠페인: 테마 = 캠페인 테마, 밴드 = clamp(floor((단계-1)/10)+1, 1, 5) → 1~10 낮 · 11~20 노을 · 21~30 밤 · 31~40 전운 · 41~50 침공 절정.
- 무한: 테마 = (floor((단계-1)/50) mod 10)+1, 밴드 = floor(((단계-1) mod 50)/10)+1 → 50단계마다 다음 테마, 500단계마다 처음으로.
- 처음 쓰는 그림만 그때 받고, 밴드가 끝나기 2단계 전에 다음 그림을 미리 받는다. 바뀔 때 0.8초 서서히 (연출 끄기면 바로), 다 바뀌면 예전 텍스처는 지운다.
- 맵 판 테두리 그림자는 그대로 두고, 위·아래 끝에 옅은 어둠을 깔아 성·성벽 위 HUD 글자를 또렷하게.

### 0.3 보스 컷인

- 단계 보스가 나오면(sim `bossSpawn` 사건) 그림이 있는 보스(`game.json art.cutins`)만: 오른쪽에서 그림이 미끄러져 들어오고 어두운 사선 띠 위에 '보스 이름 + 등장!', 잠깐 멈췄다 빠져나감.
- 실제 시간 1.6초 (×16에서도 같음), 누르기를 막지 않음, HUD 위·패널 아래, 새 컷인이 오면 예전 것을 바꿈, 움직임 줄이기 설정이면 서서히 나타났다 사라짐, 연출 끄기면 건너뜀.

### 2.1 상태

| 상태 | 반복 | 길이 | 설명 |

| 공격 | 1회 | 공격 간격의 60% 이하 | 공격 순간 재생 후 대기로 복귀. 공속이 빠르면 재생 속도도 빨라짐 |
| 특색 발동 | 1회 | 0.5~1초 | 광부 금덩이, 시간술사 정지, 연금술사 동전 등 |
| 등장 | 1회 | 0.4초 | 소환·승급 직후. 등급이 높을수록 화려 (레전드: 빛 기둥 + 착지 충격파). G-2: 아래 2.4.1 캐릭터 연출과 함께 |
| 각성 연출 | 1회 | 2초 | 타워 성장 화면에서 Lv15 달성 시 |
| 몹 걷기 | 항상 반복 | 0.6초 주기 | 이동 방향으로 몸 기울기 |
| 몹 피격·사망 | 1회 | 0.1초 / 0.3초 | 하얀 깜빡 / 납작해지며 사라짐 |
| 보스 | 걷기 + 패턴 동작 | — | 패턴 직전 0.5초 예고 동작 (몸이 빛남) |

### 2.2 대기 동작 규칙

- 대기 동작 = **기본 숨쉬기**(몸이 위아래로 2% 늘었다 줄었다, 1.5초) + **타워 고유 동작**(2~4초 주기)
- 같은 타워 여러 개가 똑같이 움직이지 않도록 **시작 시점을 무작위로** 어긋나게 함
- 고유 동작 사이에 0~1초 무작위 쉼을 넣어 기계적인 느낌을 줄임
- 공격 직후 0.3초는 고유 동작 대신 숨쉬기만
- 저사양 설정('간소화'): 고유 동작을 끄고 숨쉬기만 유지

### 2.3 제작 방식

| 단계 | 방식 | 설명 |
|------|------|------|
| **프로토타입 (채택)** | **파츠 분리 + 코드 애니메이션** | 캐릭터를 머리·몸·왼팔·오른팔·무기·소품 6개 파츠(SVG)로 나누고, 코드(트윈)로 회전·이동·크기를 움직임. 그림 몇 장으로 모든 동작을 만들고, 각성 외형은 파츠 교체로 처리 |
| 완성판 (선택) | 스프라이트 시트 | 프레임별 그림으로 교체. 동작 정의 데이터만 바꾸면 되도록 구조를 짜 둠 |

### 2.4.1 G-2 소환·승급 연출 — 주사위 대신 캐릭터 위주 (`src/view/render/Fx.ts summonFx`)

| 순서 | 소환 | 승급 |
|------|------|------|
| 0 | 등급 색 빛 기둥 (예전 그대로) | 재료 칸의 등급 색 빛 구슬이 0.3초 동안 결과 칸으로 빨려 듦 |
| 1 | 발밑 **소환문**: 눕힌 룬 고리 둘이 반대로 돌며 커졌다 사라짐 (0.6초) | 더 큰 소환문 |
| 2 | 몸 가운데 **빛 터짐** (등급 색 빛살 16개, 더하기 섞기) | 더 크고 길게 |
| 3 | 나타나는 캐릭터 모양 그대로 **하얀 실루엣 번쩍임** (그 캐릭터 그림을 하얗게 칠해 겹침, 0.4초) | 같음 (새 캐릭터) |
| 4 | **초상 카드**: 몸 가운데에서 머리 위로 떠오르며 뒷면(금테 소환문) → 앞면(그 캐릭터 초상 + 등급 색 테 + 아래 별)으로 뒤집힘, 잠깐 멈췄다 위로 사라짐 (약 0.8초) | 더 큰 카드 (0.96칸) |
| 5 | — | **등급 별**이 카드 둘레에 부채꼴로 튀어 오름 (노말 1 ~ 레전드 5, 신·리미티드 5) |

- 카드 높이 = 지금 그림 크기의 머리 끝 위(B-1 규칙, `towerGeom.cardApexTiles`). 맨 윗줄처럼 HUD 아래 끝에 막혀 얼굴을 가리게 되면 머리 옆(화면 가운데 쪽)으로 비켜 띄운다. 별도 HUD 밑으로 숨지 않게.
- 한도: 동시에 떠 있는 카드 `MAX_SUMMON_CARDS` = 12 (A-1 주사위 한도 그대로) — 넘치면 빛 기둥만. 연출 끄기면 아무것도, 동작 줄이기면 빛 기둥·빛 구슬만.
- E2E 카운터 `Game.summonFxStats` {active, shown, peak, portals, silhouettes, stars} (예전 이름 `diceStats`는 카드 수 별칭으로 남김). 물체 이름 `summon-card`·`summon-portal`·`summon-burst`·`summon-silhouette`·`merge-card`·`merge-star`·`merge-material-orb`.
- 그림: 소환문·빛 터짐·카드 뒷면/앞면/테·등급 별은 `art/fx.ts ensureSummonFxTextures`가 캔버스로 한 번 굽는다. 초상은 정보 패널과 같은 캐릭터 그림(`TowerLayer.textureKey`)을 잘라 쓴다.
- 도박꾼 특색(`dicePop`)·도박 시트의 주사위는 실제 주사위라 그대로.
