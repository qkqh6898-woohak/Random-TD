## 1. 스타일

| 항목 | 방향 |
|------|------|
| 캐릭터 | **2D SD** (2~2.5등신), 큰 머리·작은 몸. 살짝 위에서 내려다보는 시점 |
| 분위기 | 밝고 귀여운 판타지. 운·도박 요소는 카지노풍 금색·빨강 포인트 |
| 외곽선 | 진한 갈색 외곽선 2px (작은 화면에서도 형태가 보이도록) |
| 직업 표현 | 소품으로 한눈에: 광부 = 곡괭이·헬멧, 학자 = 두꺼운 책·안경, 상인 = 돈주머니, 도박꾼 = 주사위 |
| 등급 표현 | 발밑 받침대 색 + 머리 위 별 개수. 유니크 이상 은은한 빛, 레전드 이상 오라 파티클, 신은 무지개 후광 |
| 각성 외형 | 색 변화 + 장비 업그레이드 + 상시 오라 (예: 광부 → 금빛 곡괭이·보석 헬멧) |
| 맵 | 블록 = 잔디 단상, 경로 = 흙길, 장식 칸 = 나무·바위·꽃 |
| 오리지널리티 | 모든 캐릭터·몹·UI는 이 게임만의 오리지널 디자인 |

## 2. 애니메이션

### 2.1 상태

| 상태 | 반복 | 길이 | 설명 |
|------|------|------|------|
| **대기 (idle)** | **항상 반복** | 2~4초 주기 | 공격하지 않을 때도 타워마다 정해진 동작 ([TOWERS.md](TOWERS.md) 9장) |
| 공격 | 1회 | 공격 간격의 60% 이하 | 공격 순간 재생 후 대기로 복귀. 공속이 빠르면 재생 속도도 빨라짐 |
| 특색 발동 | 1회 | 0.5~1초 | 광부 금덩이, 시간술사 정지, 연금술사 동전 등 |
| 등장 | 1회 | 0.4초 | 소환·승급 직후. 등급이 높을수록 화려 (레전드: 빛 기둥 + 착지 충격파) |
| 각성 연출 | 1회 | 2초 | 타워 성장 화면에서 Lv15 달성 시 |
| 몹 걷기 | 항상 반복 | 0.6초 주기 | 이동 방향으로 몸 기울기 |
| 몹 피격·사망 | 1회 | 0.1초 / 0.3초 | 하얀 깜빡 / 납작해지며 사라짐 |
| 보스 | 걷기 + 패턴 동작 | — | 패턴 직전 0.5초 예고 동작 (몸이 빛남) |

### 2.2 대기 동작 규칙

- 대기 동작 = **기본 숨쉬기**(몸이 위아래로 2% 늘었다 줄었다, 1.5초) + **타워 고유 동작**(2~4초 주기)
- 같은 타워 여러 개가 똑같이 움직이지 않도록 **시작 시점을 무작위로** 어긋나게 함
- 고유 동작 사이에 0~1초 무작위 쉼을 넣어 기계적인 느낌을 줄임
- 공격 직후 0.3초는 고유 동작 대신 숨쉬기만
- 저사양 설정('간소화'): 고유 동작을 끄고 숨쉬기만 유지

### 2.3 제작 방식

| 단계 | 방식 | 설명 |
|------|------|------|
| **프로토타입 (채택)** | **파츠 분리 + 코드 애니메이션** | 캐릭터를 머리·몸·왼팔·오른팔·무기·소품 6개 파츠(SVG)로 나누고, 코드(트윈)로 회전·이동·크기를 움직임. 그림 몇 장으로 모든 동작을 만들고, 각성 외형은 파츠 교체로 처리 |
| 완성판 (선택) | 스프라이트 시트 | 프레임별 그림으로 교체. 동작 정의 데이터만 바꾸면 되도록 구조를 짜 둠 |

**동작 정의 예시 (`src/data/animations.json`)**

```json
{
  "miner": {
    "parts": ["body", "head", "arm_l", "arm_r", "pickaxe", "helmet"],
    "idle": [
      { "part": "arm_r", "rotate": [0, -70, 0], "duration": 0.8, "ease": "back" },
      { "part": "pickaxe", "follow": "arm_r" },
      { "fx": "dust", "at": 0.6 },
      { "part": "arm_l", "rotate": [0, -40, 0], "duration": 0.6, "label": "땀 닦기" }
    ],
    "attack": [{ "part": "arm_r", "rotate": [0, -110, 10, 0], "duration": 0.4 }],
    "special": [{ "fx": "gold_nugget", "text": "+5" }]
  }
}
```

### 2.4 이펙트

| 이펙트 | 쓰임 |
|--------|------|
| 투사체 | 화살, 마법구, 폭탄, 동전, 주사위, 표창 등 타워별 |
| 광역 원 | 폭발 반경만큼 퍼지는 원 (반투명) |
| 오라 | 지원 타워 주변 8칸에 은은한 빛 (타워 선택 시 진하게) |
| 상태 이상 | 둔화 파란 김, 기절 별, 정지 시계, 빙결 얼음, 화상 불씨, 독 보라 거품 |
| 숫자 | 피해(흰색), 치명타(노란색·크게), 돈(금색 +n원) |
| 화면 | 신 타워 강림, 보스 등장 배너, 시간술사 흑백 0.2초 |

### 2.5 성능 목표

| 항목 | 목표 |
|------|------|
| 프레임 | 60fps (저사양 30fps) |
| 화면 최대 오브젝트 | 타워 81 + 몹 180 + 투사체 200 |
| 파츠 그림 | 타워 1종당 6~8장, 전부 하나의 이미지 묶음(아틀라스)으로 |

## 3. 사운드

### 3.1 배경음

| 곡 | 쓰임 | 분위기 |
|----|------|--------|
| 타이틀 | 타이틀·메뉴 | 경쾌한 카지노풍 |
| 전투 1 | 1~19단계 | 가벼운 행진 |
| 전투 2 | 20~39단계 | 템포 상승 |
| 전투 3 | 40단계~ | 긴장감 |
| 보스 | 보스 단계 | 묵직한 북 |
| 결과 | 정산 | 클리어 = 팡파르, 패배 = 담담한 피아노 |

### 3.2 효과음

| 분류 | 효과음 |
|------|--------|
| 조작 | 소환 뽁, 승급 상승음(등급별), 이동, 버튼, 팝업 열기/닫기 |
| 전투 | 타워 계열별 공격음 (활·마법·근접·폭발·총), 몹 피격, 몹 사망 |
| 돈 | 동전 짤랑 (작게, 0.1초 안에 여러 개면 하나로 합침) |
| 도박 | 슬롯 회전, ×0 실망, ×2~3 띵, ×5 이상 잭팟 벨 |
| 경고 | 보스 등장, 보스 10초, 몹 120 이상, 목숨 감소 |
| 특별 | 신 타워 강림, 히든 조합, 각성, 레벨업 |

- 같은 효과음이 동시에 8개 넘게 나면 나머지는 생략 (소리 뭉개짐 방지)
