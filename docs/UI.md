## 1. 화면 흐름

```
앱 실행
 └─ 로딩 (업데이트 확인은 뒤에서 조용히)
     └─ 타이틀 ──┬─ [출석 팝업] (오늘 첫 접속 시 자동)
                 ├─ 캠페인 → 월드맵(테마·발판 선택) → 덱 확인 → [챕터 대화] → 게임 → 결과(정산) → 월드맵

                 ├─ 이어하기 (진행 중인 판이 있을 때만)
                 ├─ 하단 메뉴: 상점 · 타워 · 덱 · 특성 · 미션 · 업적 · 도감
                 └─ 설정
```

### 4.1 배치

> 지금 코드 기준 (G-1·피드백 #25·#26·#45·#64·#65 이후, V2.0 PR-A에서 고침). 자세한 testid는 13장.

```
┌──────────────────────────────┐
│ [×1]      WAVE 3 ⏱0:42   [⚡2][⏸]│  ← HUD 1줄 (개발자: 왼쪽 [×1][⏭][💰+]) · 준비 '준비' · 보스 '👑 WAVE 10' · 캠페인 '1-5'
│ 💰 1,240원           🗼 12/30 │  ← HUD 2줄 자원 줄 (돈 옆 '+n원'은 하나씩 따로)
│ 👾 ▓▓▓▓░░░░ 87/150            │  ← HUD 3줄 몹 수 막대 (캠페인 ❤ 목숨)
│ [보스: 박쥐 여왕 ▓▓▓▓░░ 38초] │  ← 보스·도전·[▶ 준비 완료] 자리
│                  [⏫ 모두 승급 3]│  ← 맵 오른쪽 위 (승급할 무더기가 있을 때만)
│          [ 맵 ]               │  ← 빈 칸 터치 = 소환, 빈 곳 꾹 = 연속 소환
│                              │     타워 터치 = 정보 패널 (설정 '눌러서 바로 승급'을 켜면 가득 찬 무더기는 바로 승급)
│                    [⚔][📋]   │     타워 길게 눌러 끌기 = 이동/교환 · 오른쪽 아래 둥근 도전·미션 버튼
├──────────────────────────────┤
│ 👷 2/10  (🃏)        [👷 300원] │  ← 자원 줄: 일꾼 수 · 접은 카드 알약 · 고용(꾹 = 계속)
│ [💠 리미티드][🎲 소환 22원][🎰 도박]│  ← 큰 버튼 (소환 = 지금 비용, 꾹 = 계속, 아래 '천장 n')

└──────────────────────────────┘
```

- 예전 아래 띠 [⬆ 승급 가능 n](`hud-merge-ready`)·하단 메뉴 [⚔ 도전][⬆ 강화][📋 미션] 세 칸은 없다 (피드백 #65·G-1).

### 4.2 HUD 상세

| 요소 | 표시 | 상태 변화 |
|------|------|----------|
| 단계 | 무한 'WAVE n' (준비 '준비', 보스 '👑 WAVE 10') / 캠페인 '1-5' (`hud-stage`) | 보스 단계는 왕관 |
| (종족 시너지) | HUD 표시 **없음** (계획만) | |
| 타이머 | 단계 남은 시간 | 10초 이하 노란색 |
| 몹 수 (무한) | "87/150" | 120 이상 빨간색 깜빡 + 화면 가장자리 붉은 테두리 |
| 목숨 (스테이지) | "❤ 20" | 줄 때마다 하트가 깨지는 연출, 5 이하 빨간색 |
| 돈 | "1,240원", 1만 이상 축약 | 들어올 때 +숫자가 떠오름, 일꾼 수입은 5초마다 작게 |
| 인원 | '🗼 12/30' (내 타워 수 / 인원 한도, `hud-towers`) | 가득이면 알림 |
| 일꾼 | 아래 자원 줄 '👷 3/10' (`hud-workers`) | 최대일 때 금색 |
| 배속 | ×1 / ×2 / ×4 / ×8 / ×16 (일반·개발자 모두 Lv1부터, 새 판 기본 ×1) | 누를 때마다 순환 |
| ⚡ n | 필살기가 찬 캐릭터 수 (`hud-ult`, 있을 때만) | 누르면 필살기 목록 |
| ⏸ | 일시정지 메뉴 | |

### 4.3 맵 위 조작

| 조작 | 결과 |
|------|------|
| 빈 배치 칸 터치 | 즉시 소환 (같은 캐릭터 덜 찬 무더기가 있으면 거기에 쌓임 — G-1). '두 번 터치 소환' 설정은 없다 |
| 빈 곳 꾹 누르기 (0.3초) (T-2) | 자동 칸(경로가 가장 많이 보이는 빈 배치 칸)에 연속 소환 — 초당 약 4번(연출 끄기면 약 10번), 손을 떼거나 돈·빈 칸이 없으면 멈춤. 아래 띠 [🎲 소환 22원]도 같다 (짧게 = 1개) |
| 경로·장식 칸 터치 | 아무 일 없음 |
| 타워 터치 | 타워 정보 패널 + 사거리 원 표시 + 같은 종류 타워 모두 강조. 감지 타워는 👁 감지 범위 원(보라 점선)도 표시. 가득 찬 무더기도 기본은 **패널** → [⬆ 승급]·[⬆⬆ 모두 승급] (v0.1.16 '눌러서 바로 승급' 기본 꺼짐). 설정을 켜면 패널 없이 바로 승급 |
| 패널 [↔ 이동] 뒤 칸 터치 (T-2) | 놓을 수 있는 칸 강조(빈 칸 초록·교환 파랑) + '옮길 칸을 누르세요 · 꾹 눌러 끌어도 돼요' → 빈 칸 = 이동, 내 타워 = 교환, 같은 타워·못 놓는 칸·Esc = 취소 |
| 타워 길게 누르기 (0.3초) → 끌기 | 이동 미리보기 (놓을 수 있는 칸 초록, 교환은 파랑) → 손 떼면 확정 |
| 빈 곳 터치 / 뒤로가기 | 패널 닫기 |
| 두 손가락 벌리기 | 맵 확대 (최대 1.6배), 끌어서 이동 |

### 4.4 타워 정보 패널 (화면 아래에서 반쯤 올라옴)

```
┌──────────────────────────────┐
│ [캐릭터]  ★★★ 대장장이  Lv7   │
│  (대기 동작)  유니크 · 📯지원   │
│ 물리 112  마법 —  공속 0.8 (×2.6) │
│ 사거리 1.5  범위 근접 단일        │
│ 방관 40%  마관 20%  치명 15% ×2.5 │
│ 👁 감지: 없음                     │
│ 특색: 주변 8칸 공격력 +16%      │
│ 보유: 3/3                      │
│ [⬆ 승급]  [⬆⬆ 모두 승급]          │  ← 조건 충족 시만 활성화 (리미티드 제작은 [💠 리미티드] 시트)
│ [↔ 이동] [🛠 변환]                 │  ← 변환은 개발자 모드만 · 판매는 머리 줄 [판매 +n원][✕]
│ 대상: [선두 ▼] (Lv8)            │
└──────────────────────────────┘
```

- **[판매 +n원]** (T-2, 머리 줄 `tp-sell`): 가치의 50% (`game.json sell`, GDD 4.5 — V2.0 PR-A: 노말 15원 기준, 노말·레어·신은 지금 소환 비용 − 1원 이하). 히어로·레전드·신·히든은 첫 누름에 버튼이 빨갛게 '한 번 더 누르면 판매'로 바뀌고 2초 안에 다시 눌러야 팔린다. 팔면 알림 '판매 +n원'.
- **칸 위 작은 버튼** (피드백 #47): 패널이 열리면 고른 영웅 칸 **왼쪽 위 모서리에 [⬆](승급, `tq-merge`)** 둥근 버튼(칸 너비 40%, 최소 28px · 누르는 곳 +8px)이 함께 뜬다 (`quick` 층, 패널 아래). 패널 [⬆ 승급]과 같은 명령·규칙 — 승급할 수 없으면 회색 꺼짐. 패널이 닫히면 같이 사라진다. **판매는 정보 패널 머리 줄 오른쪽 위 [판매 / +n원](`tp-sell`, [✕ 닫기] 왼쪽 — 디자인 FB-D1 #30) 하나뿐** (v0.1.14 통합: PR #51의 칸 위 [✕ 판매]·PR #56의 두 줄 칩은 판매 버튼이 둘이 되어 뺐다). 히어로 이상은 첫 누름에 빨간 '한 번 더 누르면 판매', 2초 안에 한 번 더. 패널 닫기는 [✕]·뒤로 가기·맵 빈 곳 누르기.
- **[↔ 이동]** (T-2): 패널을 닫고 이동 모드 (4.3). 길게 눌러 끌기와 같은 move 명령.
- **[🛠 변환]** (개발자 모드만): 같은 등급의 다른 타워 고르기 창 (노말~레전드 9종, 신 2종, 히든 11종 — 초상화·이름) → 그 자리에서 바뀐다.
- **설명·카드** (HF-2): 이름 아래 lore·role 두 문장(각 2줄까지), 머리줄 [ℹ](초상을 눌러도) → 캐릭터 카드(큰 초상·설명·능력치·특색·각성).
- **접기** (HF-3): 고른 타워 그림을 가리지 않게 덜 중요한 줄부터 접는다 — 1단계 승급 결과·안내 / 2단계 lore·감지·보유/대상 줄 + 버튼 두 줄을 한 줄로(글자 줄임: [⬆ 승급] [⬆⬆ 승급] [↔] [💰 +450원] [🛠]) / 3단계 role·관통 줄 / 4~6단계 특색. 한 줄로 합쳐도 버튼은 44px 이상. '이동 중'·'💫 기절' 표시는 늘 보이게 이름 줄에.

- 수치는 판 내 강화·버프가 반영된 현재 값. 버프로 오른 값은 초록색 + (기본값)
- 승급 결과로 나올 수 있는 다음 등급 5종을 작게 미리 보여줌 (예언자·점성술사 효과 시 확정 결과)

### 4.3.1 첫 10단계 안내 (F10)

- **추천 칸** (첫 소환 전): 이 판에 내 타워가 없고 소환한 적이 없으면, 자동 소환과 **같은 점수**(둘레 2칸 안 경로 칸 수 → y → x, sim `rankSummonTiles`)의 앞 3칸(`game.json guide.recommendCount`)이 금빛으로 숨 쉬고, 1등 칸에 '추천'. 판 시작 때 알림 '빛나는 칸을 눌러 소환해요'. 칸 테두리는 여전히 숨긴다 — 추천 칸 빛과 승급 강조만 보인다.
- **[▶ 준비 완료 · 바로 시작]**: 준비 단계(0단계)에서 내 타워가 1개 이상이면 HUD 보스 막대 자리에 금색 버튼 (보이는 높이는 막대 자리, 누르는 영역은 위아래로 넓혀 44px 이상). 누르면 `readyNow` 명령 → 그 틱에 1단계 시작, 다음 단계는 그로부터 60초 뒤. 연타해도 1단계는 한 번 (sim이 준비 단계에서만 받는다). 누르지 않고 60초를 기다리는 예전 진입도 그대로.
- **보유 2/3 배지**: 같은 종류(승급할 수 있는 등급)가 2개인 내 타워 발밑 오른쪽에 작은 '2/3' 알약. 패널의 '보유 n/3' 줄은 그대로.
- **승급 미리 보기**: 승급할 수 있는 타워의 패널이 열려 있거나 첫 승급 안내 중이면 **결과가 생길 칸**(고른 타워 칸) = 금색 네모 + '결과', **재료로 사라질 두 칸** = 빨간 네모 + ✕ + '재료'. 재료는 sim 규칙(고른 타워를 뺀 같은 종류 중 가장 나중에 소환된 2개)으로 계산 → 표시와 실제가 늘 같다.
- **첫 승급 안내** (계정마다 한 번, `rtd.account` guides 'firstMerge'): 처음 승급할 수 있게 되면 묶음 하나(가장 먼저 소환된 타워가 있는 묶음)를 골라 결과 칸·재료 두 칸을 강조하고 [⬆ 승급 가능] 버튼을 반짝인다(피드백 #65부터 [⏫ 모두 승급]). 카드(제목 + 한두 줄, 1/2 → [다음] → 2/2, ✕)는 강조한 칸이 맵 아래쪽이면 위(알림 자리 아래), 아니면 아래(하단 메뉴 위)에 뜬다. 카드는 누르기를 통과시키고 [다음]·✕만 받는다 → 카드 아래 칸·HUD 버튼도 누를 수 있다.
  - 눌러서 바로 승급(켜짐): 안내 중 묶음의 **다른 타워를 누르면 그 칸이 새 결과 칸**(재료도 다시 계산, 승급하지 않음), 금색 결과 칸을 누르면 승급. 꺼짐: 패널로 고른 타워가 결과 칸, 패널 [⬆ 승급]으로 승급.
  - 승급하거나 ✕를 누르면 계정에 기록하고 닫는다. 묶음이 사라지면(판매 등) 기록 없이 닫고 다음에 다시 뜬다. 이미 본 계정은 '{타워} 승급 가능!' 알림만 (예전처럼).
- **승급 결과 알림**: 승급하면 '⬆ {등급} {이름}' + 역할 한 줄(towers.json role, 46자 넘으면 줄임) 배너 2.6초 (보라 바탕·금 테두리). 판마다 처음 3번(`guide.resultToasts`), 첫 승급 안내 중이면 늘.

### 4.7 개발자 모드 · 개발자 도구 (T-1)

테스트·확인용. 일반 빌드·주소에서는 아무것도 보이지 않고 동작도 예전과 같다.

- **켜는 법** (하나라도): 주소 `?dev=1` · `?debug=1`(예전 주소) · 테스트 빌드(`npm run build:single` → `release/운빨디펜스-test.html`, `VITE_TEST_BUILD=1`). 판단은 `src/devMode.ts` 한 곳.
- **HUD 1줄 왼쪽**: `[×1] [⏭] [💰+]` (돈은 2줄 자원 줄, 일꾼은 아래 자원 줄)
  - **[⏭] 다음 단계로 즉시 이동**: 누를 때마다 다음 단계가 바로(다음 틱에) 시작되고 단계 타이머가 60초로 새로 잡힌다. 빠르게 연타해도 누른 수만큼, 길게 누르면 0.38초 뒤부터 초당 4번. 어떤 배속에서도 같다.
    - 남은 등장 대기열은 새 단계 것으로 바뀐다 (건너뛴 단계의 남은 몹은 안 나옴). 맵 위 몹은 그대로 → 몹 한도·목숨 패배는 평소 규칙대로.
    - **보스 단계에서 누르면** 보스(조각)를 보상·카드 없이 지우고 제한 시간을 끈다 → 제한 시간 패배 없음, 보스 막대 사라짐. 한 번에 보스 단계를 지나쳐도 보스는 나오지 않는다. 진행 중인 도전 보스는 자기 30초대로 남는다.
    - 캠페인은 마지막 단계(50)에서 멈춘다.
  - **[💰+]**: 돈 추가 (`game.json` debug.addGold).
  - **배속**: ×1 → ×2 → ×4 → ×8 → ×16 → ×1 (`game.json` devSpeeds, T-2에서 ×3 뺌). ×16은 실제 시간 1초에 게임 16초(320틱). 한 프레임 따라잡기 한도(250ms)는 배속을 곱하기 전 실제 시간에 적용 → ×16이면 한 프레임에 게임 시간 최대 4초.
- **🛠 개발자 도구** (T-2): 맵 오른쪽 아래 둥근 [🛠](`menu-dev`) → 바텀 시트 (4.5). '연출 끄기 (전체)'를 켜면 도박 릴(결과 바로)·피해/돈/회복 숫자·동전·맞음 불꽃·처치 연출·화면 흔들림·소환/승급 빛·특색(운석·시간 정지·주사위·웅덩이 물보라) 효과·배너/알림/시트/패널 등장 애니메이션·캐릭터 대기 동작·공격 몸짓·몹 걸음 흔들림을 모두 끈다. 타워·몹·투사체·체력 막대·HUD 숫자·알림 글자는 그대로. 개발자 모드가 아니면 저장값이 있어도 쓰지 않는다.
- **×4 이상에서 화면 연출을 줄인다** (sim 결과는 그대로): 피해 숫자는 치명타 우선, 같은 종류는 큰 피해부터 4·3·2개(×4·×8·×16), 동시에 떠 있는 숫자 24·16·12개, 맞음 불꽃·광역 연출도 줄이고, 한도를 넘은 처치·특색 돈은 동전 없이 돈 글자에 바로 더한다. 느린 기기에서 한 프레임 sim 시간이 넘치면(실제 프레임의 절반, 12~50ms) 배속 몫의 틱을 버린다 — 게임이 조금 느려질 뿐 멈추지 않는다(×1 몫은 버리지 않음).
- **📝 이번 판 기록** (F10, 🛠 설정 탭 맨 위): 게임 시간 · 첫 소환(시각·단계) · 준비 완료(시각·몇 초 일찍, 안 눌렀으면 '60초 기다림') · 첫 승급 · 보스마다 '등장 m:ss → 처치 m:ss (n초)' / '시간 초과 · 남은 체력 n%' (최근 3마리). 시각은 게임 시간(배속·일시정지와 무관) — 실제 휴대폰 시험에서 첫 승급 시간·첫 보스 결과를 적는 용도.
- 그 밖: 잠긴 도박 테이블 사용, 타이틀 [캠페인 1 (디버그)], 히든 미션 영구 기록 안 함(개발용 판), 개발자 콘솔 `window.__rtd`.
