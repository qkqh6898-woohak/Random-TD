## 1. 화면 흐름

```
앱 실행
 └─ 로딩 (업데이트 확인은 뒤에서 조용히)
     └─ 타이틀 ──┬─ [출석 팝업] (오늘 첫 접속 시 자동)
                 ├─ 캠페인 → 월드맵(테마·발판 선택) → 덱 확인 → [챕터 대화] → 게임 → 결과(정산) → 월드맵
                 ├─ 무한 모드 → 덱 확인 → 게임 → 결과 → 타이틀 / 다시 하기
                 ├─ 이어하기 (진행 중인 판이 있을 때만)
                 ├─ 하단 메뉴: 상점 · 타워 · 덱 · 특성 · 미션 · 업적 · 도감
                 └─ 설정
```

## 3. 모드 선택 → 덱 확인

| 단계 | 내용 |
|------|------|
| 모드 선택 | 카드 2장(캠페인 / 무한). 캠페인 카드에 '현재 2-30 발판', 무한 카드에 최고 기록 |
| 월드맵 (캠페인) | 테마별 발판 길 + 지휘관 캐릭터, 발판에서 시작 / 처음부터, 다음 발판 보상 미리보기 ([CAMPAIGN.md](CAMPAIGN.md) 3장) |

## 4. 게임 화면

### 4.1 배치

```
┌──────────────────────────────┐
│ 2-32  ⏱0:42  ❤ 17       ⏸ │  ← HUD 1줄 (캠페인: 테마-단계·목숨 / 무한: 단계·👾 87/150)
│ 💰 1,240원  👷 3/10  ×1     │  ← HUD 2줄 (배속 버튼)
├──────────────────────────────┤
│ [보스: 박쥐 여왕 ▓▓▓▓░░ 38초] │  ← 보스·도전 보스가 있을 때만
│                              │
│                              │
│          [ 맵 ]               │  ← 빈 칸 터치 = 소환
│                              │     타워 터치 = 정보 패널
│                              │     타워 길게 눌러 끌기 = 이동/교환
│                              │
├──────────────────────────────┤
│ [👷 일꾼 고용 300원]  [⬆ 승급 가능 2] │  ← 승급 가능한 묶음 수 (누르면 해당 타워로 카메라 이동·강조)
├─────────┬─────────┬──────────┤
│  ⚔ 도전  │  ⬆ 강화  │  📋 미션  │  ← 하단 메뉴 (누르면 바텀 시트)
│ (1 가능) │ (Lv 5)  │ (2 받기)  │
└─────────┴─────────┴──────────┘
```

### 4.2 HUD 상세

| 요소 | 표시 | 상태 변화 |
|------|------|----------|
| 단계 | 캠페인 `2-32` / 무한 `87단계` (아래에 "최고 112") | 보스 단계는 빨간 왕관, 발판 단계(10·20·30·40)는 깃발 아이콘 |
| 종족 시너지 | HUD 왼쪽 세로줄: 종족 아이콘 + "3/5" | 발동하면 테두리 금색, 연합의 힘은 무지개 |
| 타이머 | 단계 남은 시간 | 10초 이하 노란색 |
| 몹 수 (무한) | "87/150" | 120 이상 빨간색 깜빡 + 화면 가장자리 붉은 테두리 |
| 목숨 (스테이지) | "❤ 20" | 줄 때마다 하트가 깨지는 연출, 5 이하 빨간색 |
| 돈 | "1,240원", 1만 이상 축약 | 들어올 때 +숫자가 떠오름, 일꾼 수입은 5초마다 작게 |
| 일꾼 | "3/10" | 최대일 때 금색 |
| 배속 | ×1 / ×2 / ×3(Lv12) | 누를 때마다 순환 |
| ⏸ | 일시정지 메뉴 | |

### 4.3 맵 위 조작

| 조작 | 결과 |
|------|------|
| 빈 배치 칸 터치 | 즉시 소환 (설정 '두 번 터치 소환' 켜면: 1번째 터치 = 칸 선택 + "100원 소환" 말풍선, 2번째 = 소환) |
| 경로·장식 칸 터치 | 아무 일 없음 |
| 타워 터치 | 타워 정보 패널 + 사거리 원 표시 + 같은 종류 타워 모두 강조. 감지 타워는 👁 감지 범위 원(보라 점선)도 표시 |
| 타워 길게 누르기 (0.3초) → 끌기 | 이동 미리보기 (놓을 수 있는 칸 초록, 교환은 파랑) → 손 떼면 확정 |
| 빈 곳 터치 / 뒤로가기 | 패널 닫기 |
| 두 손가락 벌리기 | 맵 확대 (최대 1.6배), 끌어서 이동 |

### 4.4 타워 정보 패널 (화면 아래에서 반쯤 올라옴)

```
┌──────────────────────────────┐
│ [캐릭터]  ★★★ 대장장이  Lv7   │
│  (대기 동작)  유니크 · 📯지원   │
│ 물리 112  마법 —  공속 0.8 (×2.6) │
│ 사거리 1.5  범위 근접 단일        │
│ 방관 40%  마관 20%  치명 15% ×2.5 │
│ 👁 감지: 없음                     │
│ 특색: 주변 8칸 공격력 +16%      │
│ 보유: 3/3                      │
│ [⬆ 승급]  [⬆⬆ 모두 승급]  [💠 조합] │  ← 조건 충족 시만 활성화
│ 대상: [선두 ▼] (Lv8)            │
└──────────────────────────────┘
```

- 수치는 판 내 강화·버프가 반영된 현재 값. 버프로 오른 값은 초록색 + (기본값)
- 승급 결과로 나올 수 있는 다음 등급 5종을 작게 미리 보여줌 (예언자·점성술사 효과 시 확정 결과)

### 4.5 하단 메뉴 바텀 시트

**공통**: 화면 높이 55%까지 올라옴, 위로 끌면 85%. 게임은 계속 진행. 맵 위를 터치하면 닫힘.

| 시트 | 구성 |
|------|------|
| ⚔ 도전 | 단계 카드 목록 (보스 그림 · 이름 · 체력 · 보상 · 상태). 상태: [시작] / ⏳4:32 / 🔒. 진행 중이면 맨 위에 "진행 중 18초" |
| ⬆ 강화 | 탭 3개: **[등급 강화]** 일반·영웅·전설 3줄 / **[능력치 강화]** ⚡공속·🗡물리 관통·🔮마법 관통·💥치명 확률·💢치명 피해·🎯사거리 6줄 (+초월은 조건 충족 시) / **[도박]** 테이블 2~4개, 잭팟 게이지 10칸, 숙련도, 최근 결과 5개. 각 줄: Lv, 효과 "+40% → +44%", [비용] 버튼(길게 누르면 연속). 맨 위에 현재 공속 배율 "⚡×2.6" 표시 |
| 📋 미션 | 탭 [일반 30] [히든 ???]. 진행도 바, [받기], 맨 위 [모두 받기]. 달성한 미션은 아래로 정렬 |

### 4.6 일시정지 메뉴

[계속] [설정] [도감] [포기 (정산 진행, 경험치 ×0.8)] — 포기는 확인 팝업

## 8. 토스트·알림 문구

| 상황 | 문구 |
|------|------|
| 돈 부족 (소환) | "100원이 필요해요" |
| 돈 부족 (기타) | "{n}원이 더 필요해요" |
| 칸 없음 | "빈 칸이 없어요 — 승급으로 칸을 비워 보세요" |
| 일꾼 최대 | "일꾼이 꽉 찼어요 (10/10)" |
| 승급 가능 | "{타워} 승급 가능!" (하단 버튼에 숫자 배지, 토스트는 판당 처음 3번만) |
| 투명 몹 첫 등장 + 감지 없음 | 배너 "투명 몹 출현! 감지 타워가 필요해요 👁" |
| 편대 예고 (10초 전) | 배너 "⚠ 다음 단계: 돌파 편대 — 보석 골렘 + 고블린 떼!" + 힌트 "진흙 둔화 + 광역 추천" |
| 발판 통과 | 화면 위 금색 배너 "2-30 발판 확보! 💎80" (보상은 판이 끝날 때 정산) |
| 종족 시너지 발동 | HUD 왼쪽 종족 아이콘이 빛나며 "🌲 엘프 시너지 Ⅱ 발동: 치명타 +10%p" |
| 피해가 크게 막힘 | (판당 1번) "골렘은 물리 피해를 막아요 — 마법 타워나 관통 강화를 써 보세요" |
| 히든 조합 가능 | "무언가 특별한 조합이 가능해요… 💠" |
| 신 타워 | 전체 화면 연출 "👑 {신 이름} 강림!" |
| 도전 쿨타임 끝 | 도전 탭 배지 + 작은 알림 "도전 {n}단계 준비 완료" |
| 업데이트 준비됨 | "새 버전이 준비됐어요 — 다음 실행 때 적용돼요" |

## 9. 예외 상황 처리

| 상황 | 처리 |
|------|------|
| 앱이 백그라운드로 감 | 자동 일시정지 + 즉시 저장. 돌아오면 일시정지 메뉴 표시 |
| 전화·알림이 옴 | 위와 같음 |
| 앱 강제 종료 후 재실행 | 마지막 저장 시점(단계 시작 또는 백그라운드 전환)부터 이어하기 |
| 보스 단계와 도전이 겹침 | 둘 다 진행. 체력바 2줄 |
| 승급 연출 중 다시 터치 | 연출 0.3초, 그동안 입력 무시 |
| 소환 연타 | 0.1초 간격까지 허용 |
| 몹 150 도달 순간 | 151번째 몹이 등장하는 순간 패배 (몹이 죽는 것과 같은 프레임이면 처치를 먼저 처리) |
| 신 타워 연출 | 3초 동안 게임 정지 (타이머 포함) |
| 기기 시간 변경 | 출석·일일 미션은 마지막 기록일보다 과거면 진행 안 함 |
| 저장 파일 손상 | 자동 백업본으로 복구 시도 → 실패 시 안내 후 새로 시작 (가져오기 버튼 안내) |

## 10. 손맛 (피드백)

| 행동 | 소리 | 진동 | 화면 |
|------|------|------|------|
| 소환 | 뽁 | 짧게 | 칸에서 빛 기둥 (등급 색) |
| 승급 | 상승음 (등급별로 높아짐) | 중간 | 3개가 빨려 들어가 합쳐짐 |
| 레전드 획득 | 팡파르 | 길게 | 화면 살짝 흔들림 + 빛 |
| 도박 ×5 이상 | 잭팟 벨 | 길게 | 금화 비 |
| 보스 처치 | 승리 효과음 | 중간 | 슬로 모션 0.5초 |
| 목숨 감소 | 쿵 | 짧게 | 화면 가장자리 빨갛게 |
