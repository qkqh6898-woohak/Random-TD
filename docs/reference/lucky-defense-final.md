## 10. Random-TD에서 사용할 때

- 이 문서는 외부 게임 참고 자료다. Random-TD의 현재 사양은 해당 시점 코드, src/data, 프로젝트 문서에서 확인한다.
- 소환·모집·도박·펫 뽑기는 별개 시스템으로 명명한다. 공식 모집 확률을 전투 소환에 넣지 않는다.
- 확인 값도 버전·등급·기본/누적·%/%p·초/틱 단위를 붙인다.
- 충돌 값은 양쪽 출처와 보류 이유를 유지한다. 미확인 값은 null로 둔다. 구현에 별도 값이 필요하면 ‘Random-TD 설계 값’이라고 명시한다.
- 추후 구현은 JSON 데이터·저장 마이그레이션·결정성·관련 테스트를 포함한 별도 작업이다. 이번 문서 통합은 게임 수치·코드·저장 형식을 변경하지 않는다.
- 기존 [research.md](../../research.md)는 과거 Random-TD 코드 분석 스냅샷이다. 이 문서가 그 문서의 기준 커밋이나 당시 동작을 소급 변경하지 않는다.
