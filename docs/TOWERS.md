## 0. 읽는 법

### 0.1 스탯 항목

| 항목 | 의미 |
|------|------|
| ★ | **특색 타워**. 공격보다 고유 능력(돈·버프·제어·확률·약화·감지)이 핵심 |
| 종족 | 아트라 연합군 7종족: 현대군 · 왕국 · 드워프 · 엘프 · 다크 엘프 · 오크(착한 고블린 포함) · 요정 (+ 신 = 고대신, 히든 = 연합). 종족 시너지는 8장 |
| 원소 | 🔥화염(화상 3초 범위) · ⚡번개(연쇄) · ☠독(5초 중독) · ❄얼음(빙결 = 일시 정지) · 🟫진흙(둔화) |
| 구분 | **기본** = 처음부터 해금(기본 덱) / **해금** = 조각 10개로 해금 / 0.01% = 신 / 조합 = 히든 |
| 피해 | **물리**(방어력에 막힘) · **마법**(마법 저항에 막힘) · **혼합**(반반) · **고정**(아무것에도 안 막힘) |
| 물리 공격력 / 마법 공격력 | 1회 공격 피해. 타워 Lv1, 판 내 강화 0 기준 |
| 공속 | 초당 공격 횟수. 강화·버프로 최대 기본의 **5배**까지 오름 ([GDD.md](GDD.md) 7.1) |
| 사거리 | 공격할 수 있는 거리 (칸) |
| 공격 범위 | 한 번에 맞히는 범위: 단일 / 광역 r(폭발 반경, 칸) / 관통 n(직선 n마리) / 연쇄 n(n마리 튕김) / 다중 n(동시에 n마리) / 전체 |
| 방어 관통 | 몹 방어력을 이 비율만큼 무시 (방무). 판 내 '물리 관통 강화'와 더해짐 |
| 마법 관통 | 몹 마법 저항을 이 비율만큼 무시. '마법 관통 강화'와 더해짐 |
| 치명타 | 확률과 배율 |
| 감지 | 👁오라 r = 반경 안의 투명 몹을 **모든 타워가** 공격할 수 있게 드러냄 / 👁자신 = 자기만 투명 몹을 공격 |
| 단일 DPS | 몹 1마리에게 주는 초당 피해 (치명타 기대값·지속 피해 포함, 방어 0 기준) |
| 전투력 지수 | (단일 DPS × 공격 범위 계수) ÷ 등급 기준 DPS. 공격형 0.85~1.30, 특색형 0.40~0.90이 정상 범위 ([BALANCE.md](BALANCE.md) 2.1) |
| 특수 능력 (Lv1 → Lv15) | 특색 수치는 계정의 타워 레벨에 따라 Lv1 값 → Lv15 값으로 균등하게 오름 |
| 각성 | 타워 Lv15에 추가되는 능력 + 외형 변화 |

- 모든 타워: 타워 레벨당 공격력 +4% (Lv15 = +56%)
- 대상 우선순위는 따로 적지 않으면 '선두'
- 등급 기준 DPS: 노말 10 · 레어 35 · 유니크 120 · 히어로 400 · 레전드 1,400 · 신 6,000 · 히든 3,000
