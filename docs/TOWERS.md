## 0. 읽는 법

| 열 | 의미 |
|----|------|
| ★ | **특색 타워**. 공격보다 고유 능력(돈·버프·제어·확률·약화)이 핵심 |
| 구분 | **기본** = 처음부터 해금(기본 덱) / **해금** = 조각 10개를 모아 해금 |
| 유형 | 공격 유형 ([GDD.md](GDD.md) 5.2). r = 광역 반경(칸) |
| 공격력 | 타워 Lv1, 판 내 강화 0 기준 1회 피해 |
| 공속 | 초당 공격 횟수 |
| 사거리 | 칸 |
| 능력 (Lv1 → Lv15) | 특색 수치는 계정의 타워 레벨에 따라 Lv1 값 → Lv15 값으로 균등하게 오름 |
| 각성 | 타워 Lv15 달성 시 추가되는 능력 + 외형 변화 |

- 모든 타워: 타워 레벨당 공격력 +4% (Lv15 = +56%)
- 대상 우선순위는 따로 적지 않으면 '선두'
- 계열 태그: 🟢고블린 · 🏹궁수 · 🔮마법사 · ⚔전사 · 💰경제 · 🎲확률 · 📯지원 · ❄제어 · 💀어둠
