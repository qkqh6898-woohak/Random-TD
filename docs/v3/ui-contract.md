# V3 화면·이미지 적용 계약 — Claude 구현용

상태: **화면 설계·시범 이미지 준비 완료, 런타임 UI 미구현**. 범위는 [성장 기획](growth-plan.md)의 P0~P3이다.

## 공통

- 기존 `src/ui/design-system`의 종이 바탕·나무색 머리줄·등급 토큰·글꼴·버튼을 재사용한다. 별도 시각 테마를 추가하지 않는다.
- 320/360/412px 세로 화면. 수령·강화·선택 버튼은 최소44×44px. 머리줄·닫기는 고정하고 본문만 스크롤한다. 안전영역과 기존 알림 자리를 보존한다.
- 색 외에 자물쇠·체크·숫자·라벨로 상태를 표현한다. 배지는 실제 수령 가능/강화 가능일 때만 표시한다.
- 이미지에는 글자를 합성하지 않는다. 이름·레벨·효과·진행도는 DOM 텍스트로 제공하고, 같은 정보 옆의 그림은 중복 낭독하지 않는다.
- 진행도·가격·잠금은 메타 모델의 한 계산 결과에서 렌더한다. UI가 보상 자격을 별도로 계산하지 않는다.

## P1 영웅 상세

- 현재 능력치 아래에 Lv3/6/9/12/15 마일스톤 띠. 320px에서도5칸을 유지하되 자세한 효과는 선택한 항목 아래에 표시한다.
- 잠김은 자물쇠+필요Lv, 달성은 체크+효과. 이미 달성한 레벨은 별도 구매 버튼 없이 적용됨으로 표시한다.
- 기존 특색 설명을 남기고 추가 마일스톤 효과를 이어 보여 준다. 기존 능력을 새 보상처럼 다시 잠그지 않는다.
- 레벨업 결과는 바뀐 수치와 새로 달성한 마일스톤을 함께 표시한다. 연출은 코드 배지·짧은 트윈으로 처리한다.

## P2 유물 진열장

- 머리줄: 유물 진열장 / 탐험 열쇠 / 닫기. 그 아래 목표 유물·목표 조각 진행·다음 천장까지 횟수를 표시한다.
- 첫12종은2열 카드. 카드마다 그림48px·이름·Lv/최대Lv·조각 보유/필요량·강화 가능 여부. 미공개12종은 노출하지 않는다.
- 카드 선택 시 상세 패널에 현재 효과→다음 효과, 골드·조각 비용, [강화], [목표로 지정]. 만렙은 효과와 만렙 라벨을 보여 주고 강화 버튼을 숨긴다.
- [유물 발견]은 열쇠 비용과 확률표·천장 설명을 가까이 둔다. 부족 시 필요한 수량을 읽을 수 있게 표시한다.
- 5:1 지정 교환은 소비할 유물별 조각 수와 결과를 먼저 보여 준다. 자동으로 가치 있는 조각을 소비하지 않는다.
- 첫 유물 선택은12종 모두 이름·역할을 비교할 수 있게 하며, 경제형을 기본 정답처럼 강조하지 않는다.
- 현재3유물 그림만 준비돼 있다. 나머지9종은 자체 코드 도형의 임시 아이콘과 이름으로 구분하고, 외부 게임 그림을 가져오지 않는다.

## P3 탐험·패스·정산

- 탐험 화면 상단에 다음 성장까지 남은 보급 수, 도장 진행 n/28, 미수령 보상을 표시한다. '오늘', 연속 출석, 자정 리셋 문구를 쓰지 않는다.
- 도장28칸은7열×4행. 7/14/21/28칸 보상은 그림 외에 숫자·텍스트로도 구분한다.
- 패스는 기본/황금 트랙의 같은 진행 위치를 나란히 비교한다. 진행·보상 목록은 세로 스크롤하고 현재 칸으로 이동하는 버튼을 둔다.
- 황금 트랙 구매 전 가격·지난 칸 소급·보상 내용을 보여 준다. 미수령 보상을 없애거나 다음 시즌으로 강제 이동하지 않는다.
- 정산은 기존 보상 아래에 완료 웨이브, 보급 획득, 잔여 진행, 도장 증가, 성장 선택을 요약한다. 예: 완료27 → 보급2·잔여7. 9웨이브 판에는 기존 정산을 정상 제공한다.
- 긴 판의 여러 상자는 요약/한 번에 받기를 제공한다. 같은 판을 다시 정산하면 새 보상처럼 연출하거나 중복 지급하지 않는다.
- 정령·알·간식·초월 재화·P4~P6 버튼은 이번 화면에 노출하지 않는다.

## 구현 후 확인

- 320/360/412px, 글자130%, 긴 한글 이름, 자원0·부족·충분·만렙·미수령·이미수령 상태.
