# V3 무료 트랙 수급표 (P0 산출 — 자동 생성)

> 이 파일은 `tests/unit/v3-p0-supply-table.test.ts`가 `src/data/progression.json`·`towers.json`과 `src/meta/v3/supplyModel.ts`로 만든다.
> 다시 만들기: `V3_TABLE=1 npx vitest run tests/unit/v3-p0-supply-table.test.ts`. 평소 `npm test`는 이 파일이 최신인지 검사한다.
> **모델 산출값이다.** 실제 정산 코드로 다시 재는 검증은 P2(유물·보급)·P3(도장·패스·성장 선택) 테스트가 맡는다. 실기기·플레이 측정이 아니다.

## 가정

- 표준 전투 = **완료 10웨이브**(11웨이브 도달 후 패배), 보스 1처치, 치트 없음 → 유효 전투 1판.
- 무료 트랙만: 기존 판 정산 + 보급 + 탐험 도장 + 패스 무료 칸 + 성장 선택. **일일 퀘스트(날짜)·웨이브 길·업적·비밀 코드·성장 꾸러미·황금 트랙은 넣지 않음** (넣으면 더 빨라질 뿐).
- 무작위 값은 고정 시드 200개(영웅은 60개)의 몬테카를로. p10/p50/p90 = 빠른 10% / 가운데 / 느린 10%.
- 주력 유물 = 첫 유물 선택권으로 해금(Lv1)한 최대 Lv10 유물, 목표 지정. 강화 = 조각 1/2/3/4/6/8/10/13/16(합 63) + 골드 200/300/400/600/800/1000/1300/1600/2000(합 8,200). 판 골드는 유물에만 쓴다고 가정(상점 등 다른 사용처가 있으면 골드가 병목이 될 수 있어 '골드 병목' 열로 표시).
- 열쇠 1개 = 공개 12종 조각 1개(균등), 10번째마다 미보유 보장(모두 보유면 최저 레벨). 교환 = 아무 조각 5개 → 지정 1개.
- 영웅: 판 카드 5장을 기존 가중치로 굴려 목표 영웅이 나온 장수만 센다. 판·도장·패스 불꽃은 **모두 목표 영웅에** 쓴다고 가정(상한 쪽). 영웅 꾸러미 = 다음 레벨 비용의 카드 100%·불꽃 100%.

- 성장 선택: 보급 3개마다 = **표준 전투 3판마다 1회** (목표 3~5판 ✅). 완료 27웨이브 판이면 보급 2 + 잔여 7, 80웨이브 판이면 보급 8·성장 선택 2.
- 성장 선택 내용: 영웅 꾸러미(목표 영웅 다음 레벨 비용 전부 → **1회 = 1레벨 확정**, 만렙 영웅은 고를 수 없음) 또는 🗝️ 열쇠 2개.

## 2. 주력 유물 Lv1 → Lv10 (유효 전투 수)

| 정책 | p10 | p50 | p90 | 번 골드 중 유물에 쓴 비율 | 골드가 마지막 병목 | 완성 때 보유 유물 |
|---|---:|---:|---:|---:|---:|---:|
| 직접 경로 — 성장 선택은 모두 영웅, 교환 안 함 | 55 | **58** | 60 | 35% | 0/200 | 12/12 |
| 균형 — 성장 선택 영웅/유물 번갈아, 교환 안 함 | 54 | **56** | 59 | 36% | 0/200 | 12/12 |
| 유물 집중 — 성장 선택 모두 유물(열쇠), 교환 안 함 | 52 | **55** | 58 | 37% | 0/200 | 12/12 |
| 직접 경로 + 비주력 조각 모두 5:1 교환 | 48 | **50** | 51 | 41% | 0/200 | 12/12 |
| 최대 가속 — 유물 집중 + 모두 교환 | 42 | **44** | 46 | 46% | 0/200 | 12/12 |

- 목표 **50~70유효 전투**: 직접 경로·균형·유물 집중(교환 없음)의 가운데 값이 범위 안이어야 한다(테스트가 확인). 비주력 조각을 모두 5:1로 바꾸는 최대 가속은 더 빠를 수 있다 — 대신 다른 유물 수집이 늦어진다.
- 첫 12종 모두 해금(열쇠·천장만): 성장 선택 영웅만 p50 **22판**(p90 25), 번갈아 p50 **18판** — 목표 '1~2개월 안'보다 빠르다.

## 3. 목표 영웅 Lv1 → Lv15 (유효 전투 수)

| 등급 | 전체 비용 카드 / 불꽃 | V3 없이 (기존 판 보상만, 병목) | V3 영웅 꾸러미 Lv10 | V3 영웅 꾸러미 Lv15 (병목) |
|---|---:|---:|---:|---:|
| 노말 (10종) | 266 / 1590 | 1069 (카드) | **27** | **42** (카드) |
| 레어 (10종) | 266 / 2383 | 1776 (카드) | **27** | **42** (카드) |
| 유니크 (10종) | 217 / 3180 | 2000+ (카드) | **27** | **42** (카드) |
| 히어로 (10종) | 163 / 4770 | 2000+ (카드) | **27** | **42** (카드) |
| 레전드 (10종) | 135 / 6360 | 2000+ (카드) | **27** | **42** (카드) |

- 기존 판 보상만으로는 높은 등급의 **특정 영웅 카드**가 병목(무작위 5장 중 그 영웅이 나올 확률이 낮음)이다. 영웅 꾸러미는 카드·불꽃을 함께 주어 '카드만 받고 불꽃에 막히는' 일이 없다.
- 꾸러미를 받은 영웅도 나머지 레벨은 판 카드·불꽃으로 오른다. 불꽃을 한 영웅에 몰아준다는 가정이 빠지면 더 느려진다.

## 4. 판정 (P0)

- 성장 선택 3판마다: ✅ (표준 10웨이브 완료 기준, 긴 판은 더 빨리).
- 주력 유물 50~70유효 전투: 위 2장 p50으로 판정 — 테스트 `v3-p0-supply-table`이 범위를 확인한다.
- 무료 트랙만으로 달성: 위 계산에 황금 트랙·날짜 보상은 하나도 넣지 않았다.
- 이 표의 수치는 **후보값**이다. P2·P3 구현 뒤 실제 정산 코드로 같은 정책을 다시 재서 PROGRESS에 적는다.
