## 3. 디자인 기준

- 기존159장 캐릭터·39장 UI 아이콘과 같은 통통한 비율, 코코아색 굵은 외곽선, 평면색, 한 단계 그림자.
- 아이콘에 눈·입·사람을 넣지 않는다. 정령2종만 친근한 얼굴과 짧은 팔다리를 가진다.
- 다른 게임 캐릭터·로고·스크린샷을 프롬프트나 참조로 넣지 않는다.
- 글자·프레임·버튼 테두리·광택 그라데이션·과도한 발광·배경 장면은 제외한다.
- 물체·정령은 하나씩, 화면 약80%를 차지하고 잘리지 않게.
- 흰 배경 제거 후256px WebP로 처리하고 게임 내32/48/64px에서 검토한다.
- 기존 `tools/chunky_build.py`의 적용 가능성을 확인하되 흰 털·얼음의 손실을 자동으로 허용하지 않는다.
- 정령2장 생성은 P4 구현·알·간식 재화의 선행 도입을 승인하는 것이 아니다.

## 4. 예산과 다음 순서

1. 사용자가6장 구성과6크레딧 견적을 검토한다.
2. 생성 요청을 받으면 같은 파라미터를 재견적하고 변경 여부를 확인한다.
3. 시범6장을 생성한 뒤 휴대폰 크기·실루엣·그림체·배경 제거를 평가한다.
4. 채택된 유물3장·열쇠1장은 P0~P3 본제작18장에 포함하고, 정령2장은 후속12종에 포함한다.
5. 시범 비용을 본제작 수량에 두 번 더하지 않는다. 재생성은 별도 소비로 기록한다.
6. 전체 예산 상한120크레딧을 유지하되 본제작 전 수량·비율별 견적을 다시 제시한다.

사용자가 공유한 플랜 화면의 할인·무제한 문구가 이 요청의 모델/품질/해상도에도 적용된다고 가정하지 않는다.
계정 플랜 변경·업그레이드·결제는 수행하지 않았다.
