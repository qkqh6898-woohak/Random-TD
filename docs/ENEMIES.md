# 운빨 디펜스 — 적 상세 (몹·보스·도전 보스)

> 버전: v0.4 · 관련: [GDD.md](GDD.md) 2·5·6장, [BALANCE.md](BALANCE.md)

---

## 1. 기본 수치

| 항목 | 값 |
|------|-----|
| 일반 몹 체력 `HP(s)` | 1~20단계: `120 × 1.151^(s-1)` / 21~50: `HP(20) × 1.08^(s-20)` / 51~100: `HP(50) × 1.06^(s-50)` / 101~: `HP(100) × 1.05^(s-100)` |
| 기본 이동속도 | 1.5칸/초 |
| 무한 모드 추가 방어력 | 101단계부터 단계당 +0.5% (최대 60%) |
| 처치 보상 | 10원 + ⌊단계 / 10⌋원 |
| 단계당 몹 수 | 20마리 (분열 몹이 만드는 작은 몹은 별도) |

## 2. 일반 몹 (8종)

| 몹 | 외형 | 등장 | 체력 배율 | 속도 | 방어력 | 특수 능력 |
|----|------|------|----------|------|--------|----------|
| 슬라임 | 말랑한 초록 젤리 | 1단계~ | ×1.0 | 1.5 | 0% | — |
| 박쥐 | 작은 보라 박쥐 | 6단계~ | ×0.6 | 2.4 | 0% | 빠름 |
| 골렘 | 이끼 낀 돌덩이 | 15단계~ | ×2.0 | 1.2 | 20% | 단단함 |
| 유령 | 반투명 하얀 천 | 25단계~ | ×1.0 | 1.5 | 0% | 단일 공격을 30% 확률로 회피 (광역·전체·지속 피해는 회피 불가) |
| 분열 슬라임 | 큰 파란 젤리 | 35단계~ | ×1.5 | 1.3 | 0% | 죽으면 작은 슬라임 2마리 (각 체력 30%, 속도 1.8, 보상 없음) |
| 치유사 | 버섯 모자 요정 | 45단계~ | ×1.2 | 1.4 | 0% | 3초마다 반경 2칸 몹 체력 5% 회복 (정지 중에는 못함) |
| 방패병 | 나무 방패 든 해골 | 55단계~ (무한) | ×1.5 | 1.3 | 0% | 최대 체력 30%의 보호막. 보호막은 광역 피해를 2배로 받음 |
| 그림자 | 검은 연기 늑대 | 70단계~ (무한) | ×1.3 | 2.0 | 10% | 체력 50% 이하가 되면 2초간 투명 (공격 대상 불가) |

### 2.1 단계별 등장 구성 (20마리 중)

| 단계 | 슬라임 | 박쥐 | 골렘 | 유령 | 분열 | 치유사 | 방패병 | 그림자 |
|------|-------|------|------|------|------|-------|-------|-------|
| 1~5 | 20 | | | | | | | |
| 6~14 | 16 | 4 | | | | | | |
| 15~24 | 12 | 4 | 4 | | | | | |
| 25~34 | 9 | 4 | 4 | 3 | | | | |
| 35~44 | 7 | 4 | 4 | 3 | 2 | | | |
| 45~54 | 5 | 4 | 4 | 3 | 2 | 2 | | |
| 55~69 | 3 | 4 | 3 | 3 | 2 | 2 | 3 | |
| 70~ | 2 | 3 | 3 | 3 | 2 | 2 | 3 | 2 |

- 등장 순서는 단계마다 섞되, 치유사는 항상 무리 가운데(8~12번째)에 배치
- 51단계부터 단계마다 1.5% 확률로 **정예 몹** (체력 ×5, 크기 1.3배, 처치 보상 ×10)

## 3. 보스 (10단계마다)

- 체력 = `HP(s) × 보스 배율`, 제한시간 60초. 보스는 상태 이상 규칙이 다름 ([GDD.md](GDD.md) 5.5)
- 보스 단계에는 일반 몹이 나오지 않음 (보스 패턴으로 소환되는 몹만)
- 처치 보상: 200원 + 효과 카드 선택 + 계정 경험치 +50

| 단계 | 보스 | 외형 | 배율 | 체력 (약) | 속도 | 패턴 |
|------|------|------|------|----------|------|------|
| 10 | **킹 슬라임** | 왕관 쓴 거대 슬라임 | ×40 | 17,000 | 0.9 | 체력 50%가 되면 둘로 분열 (각각 남은 체력의 50%). 둘 다 잡아야 처치 |
| 20 | **박쥐 여왕** | 망토 두른 거대 박쥐 | ×45 | 78,000 | 1.0 | 10초마다 박쥐 5마리 소환. 15초마다 3초간 날아올라 근접 타워(사거리 2 이하)의 공격을 받지 않음 |
| 30 | **고대 골렘** | 룬이 빛나는 바위 거인 | ×50 | 187,000 | 0.7 | 방어력 40%. 체력 30% 이하가 되면 이동속도 2배, 방어력 0% |
| 40 | **망령 군주** | 낫을 든 유령 왕 | ×55 | 445,000 | 0.9 | 12초마다 3초 무적 (투명). 무적일 때 주변 몹 체력 10% 회복, 유령 3마리 소환 |
| 50 | **혼돈의 용** | 머리 둘 달린 검붉은 용 | ×60 | 1,048,000 | 0.8 | 15초마다 무작위 타워 3개를 5초 기절(공격 불가). 체력 66%·33%에서 화염 장벽: 5초간 받는 피해 -50% |

### 3.1 무한 모드 보스 (60단계~)

- 60·70·80·90·100단계 … : 위 5종이 순서대로 다시 등장 (60=킹 슬라임, 70=박쥐 여왕 …)
- 배율 ×60 고정, 패턴이 강화됨

| 회차 | 강화 내용 |
|------|----------|
| 2회차 (60~100) | 소환 수 ×1.5, 패턴 주기 -20% |
| 3회차 (110~150) | 보스 2마리 동시 등장 (각 체력 60%) |
| 4회차 (160~) | 2마리 동시 + 패턴 주기 -40% + 정예 몹 호위 4마리 |

- 체력 `2700 × 2.2^(n-1)`, 제한시간 30초, 속도 1.2. 실패해도 패배 아님 ([GDD.md](GDD.md) 6장)

| 5 | 강철 골렘 | 쇠로 된 골렘 | 63,250 | 400원 | 방어력 40%, 둔화 면역 |

## 5. 적 연출

| 상황 | 연출 |
|------|------|
| 등장 | 경로 시작점에서 '퐁' 하고 튀어나옴 |
| 피격 | 0.1초 하얗게 깜빡, 피해 숫자 (설정에서 끔 가능) |
| 둔화·빙결·독 | 파란 몸 / 얼음 덮개 / 보라 거품 |
| 사망 | 납작해지며 사라짐, 동전 아이콘이 위로 튀어 HUD 돈으로 날아감 |
| 보스 등장 | 화면 상단에 보스 이름 배너 + 경고음, 체력바·60초 타이머 표시 |
| 보스 남은 10초 | 타이머 빨간색 깜빡, 심장 박동 효과음 |
| 몹 120마리 이상 (무한) | 몹 수 HUD 빨간색, 화면 가장자리 붉은 테두리, 약한 진동 |
