## 1. 몹 스탯 항목

| 스탯 | 의미 |
|------|------|
| 체력 | `HP(s) × 체력 배율`. HP(s)는 단계별 기준 체력 (2장) |
| 방어력 | **물리** 피해를 줄임. 감소율 = 방어력 ÷ (방어력 + 100) → 방어력 100 = 50% 감소 |
| 마법 저항 | **마법** 피해를 줄임. 계산은 방어력과 같음 |
| 속도 | 초당 이동 칸 수 (기본 1.5) |
| 상태이상 저항 | 둔화·기절·정지 효과의 세기/지속시간을 이 비율만큼 줄임 |
| 목숨 피해 | 스테이지 모드에서 출구에 도달했을 때 잃는 목숨 |
| 보상 | 처치 보상 배율 (기본 10원 + ⌊단계/10⌋원) |
| 투명 | 감지 범위 밖에서는 **어떤 피해·상태이상도 받지 않음** (5장) |

## 2. 단계별 성장

| 항목 | 공식 |
|------|------|
| 기준 체력 HP(s) | 1~20: `120 × 1.151^(s-1)` / 21~50: `HP(20) × 1.08^(s-20)` / 51~100: `HP(50) × 1.06^(s-50)` / 101~: `HP(100) × 1.05^(s-100)` |
| 방어력·마법 저항 | `기본값 × (1 + 0.02 × s) + max(0, s − 100)` → 50단계에 2배, 101단계부터 모든 몹이 단계당 +1씩 추가 |
| 피해 감소율 | `A ÷ (A + 100)`, A = max(0, 방어력 × (1 − 관통%) − 고정 관통) |
| 정예 몹 | 51단계부터 몹마다 1.5% 확률. 체력 ×5, 크기 1.3배, 보상 ×10 |

## 4. 보스 (10단계마다)

- 체력 = `HP(s) × 체력 배율`, 제한시간 60초. 보스 단계에는 일반 몹이 나오지 않음 (패턴으로 소환되는 몹만)
- 처치 보상: 200원 + 효과 카드 선택 + 계정 경험치 +50
- 방어력·마법 저항도 2장 공식으로 단계에 따라 오름

### 4.1 무한 모드 보스 (60단계~)

- 60·70·80·90·100단계 … : 위 5종이 순서대로 다시 등장 (60=킹 슬라임, 70=박쥐 여왕 …). 배율 ×60 고정, 패턴 강화

| 회차 | 강화 내용 |
|------|----------|
| 2회차 (60~100) | 소환 수 ×1.5, 패턴 주기 -20% |
| 3회차 (110~150) | 보스 2마리 동시 등장 (각 체력 60%) |
| 4회차 (160~) | 2마리 동시 + 패턴 주기 -40% + 정예 몹 호위 4마리 |

## 5. 투명 몹 규칙

| 항목 | 규칙 |
|------|------|
| 투명 몹 | 투명 도둑 (35단계~), 그림자 늑대 (70단계~), 망령 군주 (40단계 보스, 항상 투명), 망령 기사 (도전 9단계), 망령 군주가 소환하는 유령 |
| 드러남 | **감지 오라** 반경 안에 들어온 투명 몹은 '드러남' 상태 → 모든 타워가 공격 가능. 오라를 벗어나면 0.5초 뒤 다시 투명 |
| 감지(자신) | 그 타워만 사거리 안의 투명 몹을 공격 가능 (다른 타워에게는 여전히 투명) |
| 드러나지 않은 투명 몹 | 대상 지정 불가 + **광역·연쇄·전체 공격, 상태이상, 지속 피해 모두 무효** |
| 화면 표시 | 플레이어에게는 일렁이는 반투명 실루엣 + 머리 위 👁 아이콘으로 보임 (어디 있는지는 알 수 있음) |
| 드러난 상태 | 보라색 외곽선 |
| 경고 | 판 위에 감지 타워가 없는데 투명 몹이 처음 나타나면 배너 "투명 몹 출현! 감지 타워가 필요해요 👁" |
| 결과 | 스테이지 모드: 투명 도둑은 출구에서 목숨 2를 깎음 → 감지 없이 35~44단계를 버티면 목숨 20개 중 약 20개 손실. 40단계 보스는 감지 없이는 처치 불가 → **감지 타워가 사실상 필수** |

## 6. 일반 몹 상세

| 몹 | 특수 능력 상세 |
|----|--------------|
| 유령 | 단일 공격(단일·근접·관통의 첫 대상·다중)을 30% 확률로 회피 → "빗나감" 표시. 광역·연쇄·전체·지속 피해는 회피 불가 |

## 8. 적 연출

| 상황 | 연출 |
|------|------|
| 등장 | 경로 시작점에서 '퐁' 하고 튀어나옴 |
| 피격 | 0.1초 하얗게 깜빡, 피해 숫자 (물리 = 흰색, 마법 = 하늘색, 고정 = 노란색) |
| 방어에 크게 막힘 | 피해의 70% 이상이 막히면 작은 방패 아이콘 (덱 상성 힌트) |
| 둔화·빙결·독 | 파란 몸 / 얼음 덮개 / 보라 거품 |
| 투명 | 일렁이는 실루엣 + 👁, 드러나면 보라 외곽선 |
| 사망 | 납작해지며 사라짐, 동전 아이콘이 HUD 돈으로 날아감 |
| 보스 등장 | 상단 이름 배너 + 경고음, 체력바·60초 타이머 |
| 보스 남은 10초 | 타이머 빨간색 깜빡, 심장 박동 효과음 |
| 몹 120마리 이상 (무한) | 몹 수 HUD 빨간색, 화면 가장자리 붉은 테두리, 약한 진동 |
