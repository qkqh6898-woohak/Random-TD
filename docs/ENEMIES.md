# 운빨 디펜스 — 적 상세 (몹·보스·도전 보스)

> 버전: v0.7 · 관련: [GDD.md](GDD.md) 2·5·6장, [BALANCE.md](BALANCE.md), [STORY.md](STORY.md) (녹스 군단), [CAMPAIGN.md](CAMPAIGN.md) (테마별 난이도)
> 모든 적은 차원 균열 너머에서 온 **암흑의 군주 녹스**의 **녹스 군단**이다. 계급: 군주 → 4천왕(군단장) → 대장 → 하수인(일반 몹).
> 데이터 원본: [`src/data/enemies.json`](../src/data/enemies.json). **표는 `python3 tools/gen_tables.py`가 자동으로 만든다.**

## 0. 녹스 군단 체계

```
👑 암흑의 군주 녹스 ─ 군주 직속: 혼돈의 용
 ├─ ⭐ 질풍의 군단장 제피라  ─ 대장 4 ─ 하수인: 박쥐, 암흑 고블린 떼          (속도·물량)
 ├─ ⭐ 대지의 군단장 고르담  ─ 대장 4 ─ 하수인: 암흑 골렘, 보석 골렘, …      (방어)
 ├─ ⭐ 역병의 군단장 모르가스 ─ 대장 3 ─ 하수인: 슬라임, 분열 슬라임, 치유사  (증식·회복)
 └─ ⭐ 그림자의 군단장 녹투르 ─ 대장 2 ─ 하수인: 유령, 투명 도둑, 그림자 늑대 (은신)
```

| 계급 | 게임에서 나오는 곳 | 체력 배율 | 연출 |
|------|------------------|----------|------|
| 👑 군주 | 캠페인 10-50, 무한 250단계마다 | ×150 | 전용 컷신 + 전용 배경음 + 3페이즈 |
| ⭐ 4천왕 | 캠페인 4·6·7·8-50, 9-50(4연전), 무한 50단계마다 | ×100 (9-50은 각 ×30) | 등장 컷인(초상화 + 대사) + 금색 이름표 + 전용 배경음 |
| 대장 | 캠페인 10~40단계와 1·2·3·5-50, 무한 10단계마다, 도전 보스 | 기본 ×40~60, 테마 최종 ×80 | 은색 이름표 "질풍 군단 · 대장" |
| 하수인 | 일반 단계 | 몹별 (3장) | 군단 색 문양 |

## 1. 몹 스탯 항목

| 스탯 | 의미 |
|------|------|
| 체력 | `HP(s) × 체력 배율`. HP(s)는 단계별 기준 체력 (2장) |
| 방어력 | **물리** 피해를 줄임. 감소율 = 방어력 ÷ (방어력 + 100) → 방어력 100 = 50% 감소 |
| 마법 저항 | **마법** 피해를 줄임. 계산은 방어력과 같음 |
| 속도 | 초당 이동 칸 수 (기본 1.5) |
| 상태이상 저항 | 둔화·기절·정지·빙결 효과의 세기/지속시간을 이 비율만큼 줄임 (빙결도 일시 정지라 포함). 보스는 이 값 대신 보스 규칙(둔화 절반·지속 30%, [GDD.md](GDD.md) 5.5)만 쓴다 |
| 목숨 피해 | 캠페인에서 출구에 도달했을 때 잃는 목숨 |
| 보상 | 처치 보상 배율 (기본 10원 + ⌊단계/10⌋원) |
| 투명 | 감지 범위 밖에서는 **어떤 피해·상태이상도 받지 않음** (5장) |

## 2. 단계별 성장

| 항목 | 공식 |
|------|------|
| 기준 체력 HP(s) | 1~20: `120 × 1.151^(s-1)` / 21~50: `HP(20) × 1.08^(s-20)` / 51~100: `HP(50) × 1.06^(s-50)` / 101~: `HP(100) × 1.05^(s-100)` |
| 방어력·마법 저항 | `기본값 × (1 + 0.02 × s) + max(0, s − 100)` → 50단계에 2배, 101단계부터 모든 몹이 단계당 +1씩 추가 |
| 피해 감소율 | `A ÷ (A + 100)`, A = max(0, 방어력 × (1 − 관통%) − 고정 관통) |
| 정예 몹 | 51단계부터 몹마다 1.5% 확률. 체력 ×5, 크기 1.3배, 보상 ×10 |

### 3.4 조합 편대 (특수 몹이 섞여 막기 어려운 단계)
