# V2.0 PR-A 판 안 경제 (소환 비용 22원 · 오름)

> 사용자 결정: 일반 소환 비용 = **기본 22원, 소환할 때마다 +2원, 최대 200원, 웨이브가 바뀌어도 초기화 없음**.
> 판매가는 소환 비용과 떼고, 판매로는 절대 돈을 벌 수 없게. 나머지 가격은 판 흐름(첫 보스 클리어율)이 지금과 비슷하게 다시 놓는다.
> 모든 수치는 JSON(`src/data/game.json`·`cards.json`·`enemies.json`)에 있다. 이 문서는 그 값과 이유를 적는다.

## 1. 규칙

| 항목 | 규칙 | 코드 |
|------|------|------|
| 소환 비용 | `min(costMax, cost + costStep × n)` — n = 그 플레이어가 **돈을 내고 한 일반 소환** 횟수 (`state.summonCount[p]`, 판 상태·해시에 들어감). 22 → 24 → … → 89번째부터 200 | `Summon.summonBaseCost/summonCost` |
| 세지 않는 것 | 소환 도박(가격이 따로), 카드 '쌍둥이 소환'의 덤, 개발자 놓기, 실패한 소환 | `Summon.noteSummonPaid` (일반 소환·옛 summon 명령만) |
| 웨이브 | 단계가 바뀌어도 n은 그대로 | — |
| 할인 카드 | '소환 할인' −20%, '단골 할인' −10% (비율, 예전 −20원·−10원). 합 최대 50%. **기본 비용(22원) 아래로는 안 내려감** → 22~27원 구간에서는 할인이 거의 없다 (보스 카드는 10단계부터라 그때 비용은 보통 80원 이상) | `Cards.applyCard`, `summonCost` |
| 판매가 | 가치 = `sell.baseValue`(30) × 등급 배율(1·3·9·27·81, 신 = 레전드), 리미티드 = 재료 가치 합, 판매가 = 가치 × 50% | `rules.buildTowerValues` |
| 되팔기 막기 (검토 H2) | 일반 소환이 낼 수 있는 등급(**노말·레어·신**, `rules.summonOutcomeGrades`)은 판매가 ≤ **⌊(주인의 지금 소환 비용 − 1) ÷ 2⌋원**. ÷ 2는 카드 '쌍둥이 소환'(한 번 값에 둘) 때문 — 둘을 팔아도 2 × ⌊(c − 1)/2⌋ < c. 소환 비용은 22원 아래로 안 내려가고 소환할수록 오르므로 어떤 할인·확률(행운의 여신·소환 확률 강화·개발자 확률·신의 눈길)·쌍둥이 상태에서도 소환 → 판매는 손해다. 그래서 첫 소환 무렵 노말은 10원, 소환 비용 31원(5번째)부터 표 판매가 15원 | `Sell.sellPriceFor` |
| 승급 산물 | 등급 k 판매가 < 22 × 3^k (재료를 가장 싸게 소환한 비용 합) — 데이터 검사(`load.ts crossCheckT2`)가 지킨다 | |
| 소환 도박 결과 | 어떤 결과든 판매가 < 그 도박 가격 (테스트). 자동 판매는 **소환 도박 결과를 팔지 않는다** (검토 L4, `Sell.isAutoSellSummon`) | |

## 4. 남은 것 · 사용자 확인이 필요한 것

- **숫자 승인**: 처치 보상 곡선(초반 1/3)·도박 ×2·판매가(예전의 30%)는 에이전트 판단이다. 판 초반에 '+3원'이 뜨는 것이 체감상 괜찮은지 확인 필요.
- 소환 횟수가 늘어(첫 보스까지 약 41회, 예전 38~42회로 비슷) 모집 게이지(소환 5회당 1칸)·일일 퀘스트 '소환 50번'·미션 '소환 n회'의 체감은 거의 같다. 후반 소환 횟수는 줄어든다(비용 200원).
- 2인 판: 소환 횟수는 플레이어별이지만 돈(`state.gold`)과 할인(`summonDiscountBp`)은 지금처럼 판 하나 — 멀티를 만들 때 정리.
- 판매가 상한(⌊(지금 소환 비용 − 1) ÷ 2⌋)은 승급으로 만든 레어·주운 신에도 걸린다 (판 초반 레어 판매가 10~45원 — 비용 91원부터 45원, 신은 최대 99원). 신을 팔 일은 드물어 단순한 규칙을 골랐다.
- 남은 운 요소: '2등급 승급'(행운의 여신·개발자 확률)으로 노말 3개 → 유니크(135원)가 나오면 재료 소환 비용(≥ 66원)보다 비싸게 팔린다 — 확률이 낮고(봇 기준 수 %) 소환 비용이 계속 올라 되풀이 돈벌이는 안 된다. 예전(300원 → 450원)과 같은 구조.
